# old/data：旧数据（只读）

本目录保存旧版模型使用的数据和 tracker 的历史归档。新代码不要读这里。

## 1. 旧工作簿 `outbreak_data.xlsx`

这是旧课程实验使用的最终版工作簿：

- 窗口：W25–W41（2026-06-15 至 2026-10-11），共 17 个周度点；
- 范围：7 个省、65–66 个卫生区；
- W25：1,193 确诊 / 535 死亡；
- W41：9,066 确诊 / 4,381 死亡；
- W43 端点：10,060 / 4,887（旧代码作为 holdout，不参与拟合）；
- 总人口：36,893,224（7 个受影响省的 WorldPop 2026）。

主要工作表：

| 工作表 | 内容 |
|---|---|
| `01_报告周序列` | 原始周报序列（含康复、在隔、医护、床位） |
| `01b_两套序列对比` | 回顾口径与报告口径对比；旧拟合用回顾口径 |
| `02_分省周序列` | 分省周度数据 |
| `02b_卫生区快照_1014` | 66 个卫生区快照 |
| `03_干预时间线` | 宣布疫情、PHEIC、疫苗分配、PoC 停运等事件 |
| `03b_日度干预强度` | 日度社区/机构死亡、随访率、隔离比 |
| `03c_周度干预强度` | 周度社区死亡占比、随访率、隔离比 |
| `04_数据字段与校准锚点` | 字段定义与 CFR、隔离比、社区死亡占比等锚点 |
| `05_人口地理` | WorldPop 2026 分省人口 |
| `06_来源台账` | L01–L14 文献/来源编号 |
| `07_读图与口径校验` | 读图与口径检查 |
| `08_参数数据` | 旧 Q2 使用的固定参数与初值 |

旧代码 `load_data.m` 默认 `useTracker=false`，读 sheet 2（周序列）和
sheet 4（卫生区快照）。

## 2. `ebola_tracker/`：2026-11-08 及更早的归档

这是 tracker 数据源的历史归档，共 22 个文件，包括：

- **2026-11-08 快照**（SitRep 178）：10,990 例 / 5,354 死，8 省 67 区；
- **2026-10-25 日度表**：`ebola_daily_to_20261025.xlsx`，含国家级、省级、
  卫生区级日度数据，以及 66 区汇总；
- **旧 vs 新对比**：`old_vs_new_comparison.xlsx` 及三个 comparison CSV；
- **历史周序列**：`national_weekly_20261108.csv`、`weekly_model_input_W25-W43.csv`；
- **省/区/跨境/响应快照**：`province_latest_20261108.csv`、
  `health_zone_latest_20261108.csv`、`cross_border_latest_20261108.csv`、
  `response_latest_20261108.csv`；
- **补充数据**：`legacy_weekly_supplement_W29-W41.csv`（医护、床位、在隔）；
- **旧 tracker 临时拟合**：`fit_latest_tracker_metrics_aux.csv`（仅历史对照）。

新代码使用的是 `ws/new/data/ebola_tracker/` 中的 2026-11-11 快照；
这里的 2026-11-08 数据只用于复现旧结果和对照两套序列。

## 3. 两套序列不要混用

| 序列 | W25 | 口径 |
|---|---|---|
| 旧工作簿 | 1,193 / 535 | WHO AFRO 回顾口径 |
| tracker | 1,048 / 267 | INSP 日度汇总 |

旧代码用旧工作簿；新代码用 tracker。两套序列的 W25 锚点不同，
不能拼接，也不能用一套的累计值去减另一套的周新增。
