## 2. 逐维度点评：三方案各自对在哪、错在哪

### 2.1 旧报告（课程实验水平，骨架可用）

**做对的**：
- `σ=0.70、κ=3、ν=3.5` 全部文献固定，方向正确。
- **`γ=0.21` 有据**（2012 年刚果（金）BDBV 中位病程 15–18 天 → `γ+μ≈0.42`），比我初版的 0.35 更合理——已采纳。
- **CFR 软约束**（`rCFR = 5·(CFR_model − 0.483)`）：用"病死比例"这条稳定观测钉住 μ，思路好。
- **相对残差 + floor**（`max(C_obs,50)`）：防止早期小基数主导，思路对。

**缺的**（新题硬性要求，不改答不上）：
- 数据窗口停在 W25–W41，题面的 10,060/4,887 变成 holdout，与"当前阶段"叙述冲突。
- **无数据质量处理**：W30 原始差分含回顾补报，会判错峰值周 3 周。
- **无观测映射**：把模型 `C` 直接当确诊数，漏报、延迟全没建模。
- **无不确定性**：只有点估计，新题 Task 2 明确要求"讨论不确定性来源"。
- **无医院通道**：新题 Task 1 硬性要求人际+医院+葬礼三通道。
- **8–10 个自由参数**在旧报告的 4 参数面前反而是退步（见下）。

### 2.2 适配方案（差异清单对，参数方案偏粗）

**做对的**：切 tracker、质量标记表、`ρ_rep`+延迟核、bootstrap/profile/相关矩阵、`state_at` 回溯、额外观测锚定——**方向全对**，是这次方案的底座。

**偏粗的**：
- **待估参数仍列 8–10 个**，但 19–21 个周点、2 条曲线根本识别不了；它自己承认"βh 与 α 共线"却没给解法，只写"加先验"。
- **目标函数用相对残差 + Huber**，对指数增长数据不如对数尺度稳。
- **`ρ_rep` 没和 CFR 联动**，漏报率孤立地飘，无法解释"粗 CFR 48.6% 高于历史 Bundibugyo 25–40%"这个数据矛盾。

### 2.3 我的方案（在适配方案上补了三处硬伤）

1. **重参数化**：`βc, βh, βf` → `βc + ρh + ρf`，从"3 自由"降到"1 自由 + 2 先验"，结构性消掉 βh/α 共线——这是适配方案缺的关键一步。
2. **对数尺度目标函数**：替代 5 段相对残差，对乘性误差更对称。
3. **CFR 联动**：`CFR_obs = CFR_model/ρ_rep`，把漏报率和病死率绑在一起，给出 `ρ_rep` 的病程自洽约束。

**但仍要从另外两处继承**：旧报告的 CFR 软约束、适配方案的额外观测锚定表（我原文档只做了一半）。

## 3. 最终数据处理方案（照此执行）

### 3.1 数据准备：tracker + 三锚点断言 + 质量标记

**第一步不是画图，是写死三个断言**（防止口径读错）：

```
断言 W25 = 1,048 例 / 267 死
断言 W43 = 10,060 例 / 4,887 死   ← 题面「当前」口径
断言 W45 = 10,990 例 / 5,354 死
```

然后建**质量标记表**（逐周标异常 + 处理）：

| 周 | 异常 | 处理 |
|---|---|---|
| W26 | 国家行 WHO 手工读数 | 周锚点取 6-27 的 1,274/360 |
| W30 | 周新增 839 含 272/174 补报 | 用 `new_*_adj` |
| W44 | 死亡差含 Ituri `+346/−269` | 死亡不作真实新增 |
| 10/30–31 | harmonisation | 剔除 |
| 11/02 | reconstructed | 剔除 |

**铁律**：累计序列用 `new_*_adj` 累加；周新增只做诊断，不做拟合目标。

### 3.2 初值重建：`state_at()` 统一回溯

`Q0/R0` 不可观测，必须与所选序列**同源**，禁止混搭旧周报的 `Q0=196`。回溯规则：

| 分量 | 方法 |
|---|---|
| `C(t*), M(t*)` | 直接取序列累计值 |
| `Q(t*)` | `etc_admitted(t*)`，或 `隔离比×(C−M−R)` |
| `R(t*)` | 累计康复（tracker 仅国家级） |
| `I(t*)` | `max(C−M−Q−R, 0)` |
| `E(t*)` | `周新增(t*)/σ` |
| `D(t*)` | `安葬延迟/7 × 周死亡(t*)` |
| `S(t*)` | `N − E − I − Q − R − M` |

### 3.3 参数四分类（固定 / 锚定 / 待估 / 先验）

| 类别 | 参数 | 值 / 范围 | 确定方式 |
|:---:|---|---|---|
| **固定** | `σ` | 0.70 | 潜伏期 10 天 |
| | `γ=γQ` | 0.21 | BDBV 病程 15–18 天 |
| | `ν0` | 3.5 | 安葬 2 天 |
| **锚定** | `α` | 由隔离比反推 | `α=(γQ+μQ)·隔离比/(1−隔离比)` |
| | `μ` | 由死亡序列 + CFR | `CFR=μ/(γ+μ)` |
| **待估** | `βc0, u1, u2, α0, μ, ρ_rep` | 6 个 | 对数 NLS 拟合 |
| **先验** | `ρh=βh/βc` | 0.3–0.5，强制 `<1` | 医护占比 2.4% 下界 |
| | `ρf=βf/βc` | 2.86–3.83 | 文献 κ |

### 3.4 重参数化（核心，消共线）

```
βc(t) = βc0 · [1−u1·𝟙(t≥t1)] · [1−u2·𝟙(t≥t2)]
βh(t) = ρh · βc(t)
βf(t) = ρf · βc(t)
```

节点位置 `t1, t2` **由干预时间线固定**（PHEIC 5 月 / 疫苗 rollout 8-26 / 平台期 W41），只估降幅 `u_k`；AIC/BIC 在 2/3/4 节点间选。**另做一次旧报告式的 τ 网格搜索作敏感性**，验证"变点是否真落在干预日期附近"。

### 3.5 额外观测锚定（继承自适配方案 §3.5，全采用）

| 额外观测 | 约束 |
|---|---|
| `etc_admitted` / `etc_occupancy` | `Q` 量级与 `α` |
| 医护累计 269/47 | `βh`（下界证据） |
| 社区死亡占比 0.595–0.674 | `μ` 与 `ν` 相对大小 |
| `contacts_seen_pct` | `φ_T` |
| 累计康复 869→2,951 | `γ, γQ` |

### 3.6 观测方程（漏报 + 延迟 + CFR 联动）

```
C_obs(t) ≈ ρ_rep · C_model(t − d_c)
M_obs(t) ≈ M_model(t − d_m)         % 死亡基本全报，ρ_M≈1
```

- `d_c, d_m` 取 0–1 周（几何/Gamma），先固定 0 试算。
- **CFR 联动**：`CFR_obs = CFR_model/ρ_rep = 48.6%`；`ρ_rep` 过低会使病程超 20 天，偏离 BDBV 的 15–18 天 → 这是 `ρ_rep` 的病程自洽约束。
- **CFR 软约束**（继承旧报告）：目标函数里加 `5·(CFR_model − 0.483)` 项，把 μ 钉在病死比例这条稳定观测上。

### 3.7 目标函数与优化

```
J(θ) = Σ[log C_model − log C_obs]²
     + λ·Σ[log M_model − log M_obs]²
     + w_cfr·(CFR_model − 0.483)²
     + 先验惩罚(ρh<1, ρ_rep∈[0.5,0.9], βc0>0)
```

- 对数尺度：乘性误差同方差，1000→10000 跨度权重天然均衡。
- `fmincon` + `MultiStart`（≥8 初值），参数对数参数化保证正值。

### 3.8 不确定性量化

| 手段 | 做法 | 回答 |
|---|---|---|
| 分块 bootstrap | 周新增残差分块重采样（块长 2–3 周），500–1000 次 | 参数 95% CI、情景带 |
| profile likelihood | 只对 `ρ_rep, α, ρh` 各扫 15–20 值 | 能否识别 |
| 参数相关矩阵 | 直接报 | βh 与 α 是否共线 |
| 留出验证 | W44–W45 前向验证 | 过拟合与否 |

> 累计序列周间强自相关，普通 i.i.d. bootstrap 会低估方差，必须分块。

## 4. 为什么这套方案好（关键优势）

1. **自由参数 6 个，不是 8–10 个**——19–21 个周点配 6 参数才谈得上可识别。
2. **共线是"结构性消掉"的**——重参数化 `βc+ρh+ρf`，而不是"加先验硬压"。
3. **漏报率和病死率绑在一起**——一条 CFR 联动，同时解释了"48.6% vs 历史 25–40%"的数据矛盾。
4. **三锚点断言 + 质量标记表**——口径错在第一行就被拦住，不会算到最后才发现。
5. **能固定的固定、能锚定的锚定、剩下的才拟合**——每条参数都有出处，评委可查。

## 5. 相对适配方案的 5 处修正（一句话）

| # | 适配方案 | 最终方案 | 原因 |
|---|---|---|---|
| 1 | 8–10 待估参数 | 6 个 | 周点数不够，8+ 必过拟合 |
| 2 | 3 个独立 β | 重参数化 `βc+ρh+ρf` | 结构性消 βh/α 共线 |
| 3 | 相对残差 + Huber | 对数尺度 | 乘性误差更对称 |
| 4 | `ρ_rep` 孤立 | `ρ_rep` 与 CFR 联动 | 解释 48.6% 与 25–40% 矛盾 |
| 5 | 承认共线无解法 | 重参数化 + 聚焦 profile | 正面回答"能识别到什么程度" |
