# 第五问敏感性分析思路（Task 5）

> 定位：在 Q2/Q3 模型上做敏感性、结构不确定性与政策稳健性。
> 不重新拟合主模型；用 Q2 bootstrap/profile 的结果作为输入分布，
> 用 Q3 的干预情景作为政策输出。

## 0. 一句话

第五问不是“再做一次 OAT”，而是三层：

```text
参数层：LHS + PRCC/Sobol → 哪个参数影响最大
结构层：模型变体 → 结论是否依赖结构
情景层：数据/病毒/冲突/行为 → 政策是否稳健
```

---

## 1. 题目要求对照

| 题目要求 | 对应做法 |
|---|---|
| 识别影响最大的参数 | Morris 筛选 + LHS/PRCC + Sobol |
| 数据质量不确定性 | 报告率、延迟、缺失、省级不平衡 |
| 参数估计不确定性 | Q2 bootstrap/profile 区间 |
| 病毒株特征 | σ、γ、μ、CFR、传播力、疫苗效力情景 |
| 武装冲突动态 | βc、α、ν、疫苗覆盖的冲击情景 |
| 社区行为变化 | βc/接触率 ±20–40% 情景 |
| 不同情景稳健性 | 结构/情景矩阵 + 政策排名/regret |
| 局限与政策提示 | 阈值、区间、不可识别参数披露 |

## 2. 三层敏感性

### 2.1 参数层（global SA）

输入因子（第一版 12–15 个）：

| 因子 | 范围/来源 |
|---|---|
| `βc0` | 0.10–0.14（Q2 bootstrap） |
| `u1` | 0.30–0.60 |
| `u2` | −0.50–0.95（弱识别，另做结构情景） |
| `α0` | 0.12–0.27（Q2） |
| `μ` | 0.031–0.038 |
| `ρ_rep` | 0.5–1.0（基线 1，自由 0.885） |
| `ρh0` | 0.30–0.50 |
| `ρf0` | 2.86–3.83 |
| `ν` | 0.35–0.70 /天 |
| `σ` | 0.07–0.13 /天 |
| `γ=γQ` | 0.02–0.05 /天 |
| `E0` | ±50% |
| `D0` | ±50% |
| 观测延迟 | 0–7 天 |
| 干预效果（Q3） | 追踪 0.78–0.95、疫苗 0.5–0.9、治疗 0.3–0.5 |

输出：

- 2027-06-30 累计病例/死亡；
- 峰值日新增/周新增；
- 持续时间；
- `R0late` / `Reff` 终点；
- 核心干预包避免的病例/死亡（Task 3）。

### 2.2 结构层（structural SA）

不要把这些当作普通 Sobol 因子：

- 2 节点 vs 3 节点；
- 第二节点 9/20 vs 10/11 vs 11/01（τ 网格）；
- `ρ_rep=1` 固定 vs 自由 0.885；
- `ρh0=0.4` vs 0.3/0.5（R0 分解）；
- `ρf0=3` vs 2.86/3.83；
- `ν=0.5` vs 0.35/0.7；
- 医院通道开/关（`βh=0` vs 0.4βc）；
- 观测延迟 0 vs 7 天；
- 疫苗/PEP 泄漏近似 vs 加 V 仓室（若实现）。

输出：每个结构变体下，参数排名是否变化、政策排名是否变化。
这比“把 βh/βf/ν 硬塞进 Sobol”诚实得多。

### 2.3 情景层（scenario SA）

| 情景 | 做法 |
|---|---|
| 数据质量 | 报告率 0.5–1.0、延迟 0–7 天、省级缺失 |
| 病毒株 | σ/γ/μ、CFR、传播力、疫苗效力 |
| 冲突 | βc 短期冲击、α↓、ν↓、疫苗覆盖↓、治疗可及性↓ |
| 行为 | βc ±20–40%、葬礼习俗变化、接触率变化 |
| 空间（Task 4） | 流动强度 m 0.5–5%/周、边境管控 0–100% |

情景不是“随机噪声”，要有时间路径：

```text
冲击 = 阶跃 + 恢复时间（如 4–12 周）
```

## 3. 方法组合

### 3.1 筛选：Morris

- 15 个因子，20 条轨迹；
- 计算 elementary effects；
- 目的：先淘汰明显不敏感因子，降低 Sobol 维度。

### 3.2 全局：LHS + PRCC

- LHS 1000–2000 组；
- 对输出做秩变换，计算 PRCC；
- 给出因子排序 + 95% bootstrap CI；
- 对非线性/非单调输出也稳。

### 3.3 方差分解：Sobol

- 取 Morris/PRCC 前 6–8 个因子；
- Saltelli 方案：`N=512/1024`，`N(2k+2)` 次；
- 输出一阶 `S_i` 与总效应 `S_Ti`；
- 如果模型运行太慢，先用 LHS 训练 Gaussian Process/多项式混沌代理，再在代理上算 Sobol。

### 3.4 稳健性：bootstrap + 结构矩阵

- 用 Q2 的 500 组 bootstrap 参数作为输入分布，重算排名；
- 检查排名在不同结构变体下是否稳定；
- 输出“排名翻转”的因子对。

## 4. 政策稳健性

Task 5 不只是参数排序，还要回答“政策制定者能不能依赖”。

### 4.1 政策排名

对 Q3 的核心包、疫苗包、治疗包、全包，在不同参数/情景下计算：

- 避免病例；
- 避免死亡；
- 持续时间；
- 资源量/成本（Task 6）。

输出每个情景下的 package 排名。

### 4.2 Regret

```text
regret(package, scenario) =
    best outcome(scenario) − outcome(package, scenario)
```

选择 **minimax regret** 或 **平均 regret 最小** 的方案；  
如果不同准则给出不同 package，正文要说明。

### 4.3 阈值

- `Reff=1` 所需的追踪覆盖率/疫苗效力/治疗覆盖；
- 保持“核心包优于单项”的最小疫苗效力；
- 冲突导致 `βc` 上升多少会让结论翻转。

阈值比“某个参数 Sobol 指数 0.3”更有政策意义。

## 7. 最容易出错的地方

1. **把不可识别参数当独立 Sobol 因子**：`βh/βf/ν` 应做结构情景，不是独立采样；
2. **范围拍得太宽**：Sobol 排名会被范围支配；范围必须有 bootstrap/profile/文献依据；
3. **忽略相关性**：βc0/u1、α0/μ 相关；LHS 独立采样会不真实，必要时用 bootstrap 样本/ copula；
4. **只报一阶 Sobol**：交互作用看总效应 `S_T`；
5. **用 PRCC 当因果**：它只是秩相关；
6. **不检查排名稳定性**：bootstrap/结构变体下排名可能翻转；
7. **政策结论只用点估计**：必须给区间/regret；
8. **省级/跨境缺失**：Task 5 先做国家；空间敏感性在 Task 4 后补。

## 8. 最小可行版本

1. 12 个因子，Morris 20 轨迹；
2. LHS 1000，PRCC；
3. Sobol 只对前 6 个因子，N=512；
4. 4 个结构变体（2/3 节点、9/20 vs 10/11、ρrep 固定/自由、ρh0 0.3/0.5）；
5. 3 个情景（数据质量、冲突、行为）；
6. 政策排名：核心包 vs 全包 vs 单项最强；
7. 输出 tornado、Sobol、regret、阈值。
