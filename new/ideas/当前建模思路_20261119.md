## 3. Task 1 模型：日尺度三通道 SEIQRD

### 3.1 状态与方程

状态：

```text
S 易感者
E 潜伏者
I 有症状、未隔离感染者
Q 隔离收治者
R 康复者
D 尚未安全处理的传染性遗体
M 累计死亡（辅助量，D⊂M）
```

感染项：

```text
Λ(t) = S/N · [βc(t) I + βh(t) Q + βf(t) D]
βh(t) = ρh0 · βc(t)
βf(t) = ρf0 · βc(t)
βc(t) = βc0 · (1 − u1·1(t≥t1)) · (1 − u2·1(t≥t2))
```

ODE：

```text
dS/dt = −Λ
dE/dt = Λ − σE
dI/dt = σE − (α + γ + μ)I
dQ/dt = αI − (γQ + μQ)Q
dR/dt = γI + γQ Q
dD/dt = μI + μQ Q − νD
dM/dt = μI + μQ Q
C = I + Q + R + M
```

当前拟合中：

- `βc(t)` 有两个节点：2026-08-17、2026-10-11；
- `α, γ, γQ, μ, μQ, ν` 在拟合中为常数；
- Task 1 方程允许 `α(t)`、`ν(t)`，但当前估计没有把它们做成时变，这是 Task 1 的
  “部分符合”点。

### 3.2 R0 与 Reff

```text
a = α + γ + μ
b = γQ + μQ

R0 = βc/a + αβh/(ab)
     + (βf/ν)(μ/a + αμQ/(ab))
   = Rc + Rh + Rf

Reff(t) = S(t)/N · [βc(t)/a + αβh(t)/(ab)
          + (βf(t)/ν)(μ/a + αμQ/(ab))]
```

### 3.3 观测方程

```text
C_obs(t) ≈ C0 + ρ_rep · (C_model(t) − C_model(0))
M_obs(t) ≈ M0 + (M_model(t) − M_model(0))
CFR_obs(t) = M_obs(t)/C_obs(t)
CFR_model(t) = M_model(t)/C_model(t)
```

- 基线没有观测延迟；延迟 0–7 天只作为待做/敏感性项；
- CFR 只做软约束，不写成 `ρ_rep = CFR_model/CFR_obs` 的恒等式；
- 周聚合残差只做稳健性校验，不作为主拟合目标。

## 4. Task 2 参数估计

### 4.1 参数分类

| 类别 | 参数 | 值/范围 | 说明 |
|---|---|---|---|
| 固定 | `σ` | 0.10 /天 | 潜伏期约 10 天 |
| 固定 | `γ=γQ` | 0.03 /天 | BDBV 病程 15–18 天 |
| 固定 | `ν` | 0.50 /天 | 安全安葬约 2 天 |
| 固定/敏感性 | `ρh0=βh/βc` | 0.40 | 无直接数据，0.3–0.5 敏感性 |
| 固定/敏感性 | `ρf0=βf/βc` | 3.00 | 文献 κ 近似，2.86–3.83 敏感性 |
| 待估 | `βc0, u1, u2` | 正数 / 有界 | 社区传播与两个节点降幅 |
| 待估 | `α0, μ` | 正数 / 有界 | 隔离收治率、未隔离病死率 |
| 基线固定/敏感性 | `ρ_rep` | 1；自由 0.885 | 病例报告比例；实际自由参数为 5 个 |

### 4.2 估计方法

```text
J(θ) = Σ_t w_t [log C_model − log C_obs]²
     + λ · Σ_t [log M_model − log M_obs]²
     + w_cfr · (CFR_model − CFR_obs)²
     + 弱先验
```

- `lsqnonlin`，MultiStart 8；
- 日残差为主，周聚合残差加一层；
- CFR 软约束；
- 固定参数由文献/情景给出，估计参数有界；
- Q2 对齐版使用 500 次 14/21 天块 bootstrap、profile `α0/ρ_rep`、
  `ρh0` 三点敏感性、2/3 节点 AIC/BIC、第二节点 τ 网格。

### 4.3 当前主结果

| 口径 | `βc0` | `u1` | `u2` | `α0` | `μ` | R² 病例/死亡 | holdout MAPE | AIC |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| P1，10/11，3 初值 | 0.12165 | 0.43153 | −0.49852 | 0.30222 | 0.03485 | 0.9970/0.9931 | 3.02%/0.57% | −1351.61 |
| Q2，10/11，8 初值 | 0.11730 | 0.44216 | −0.50000 | 0.22953 | 0.03481 | 0.9964/0.9934 | 3.95%/1.23% | −1352.64 |
| **Q2，9/20，8 初值** | **0.11251** | **0.48919** | **−0.50000** | **0.16979** | **0.03488** | **0.9972/0.9942** | **1.91%/0.79%** | **−1359.97** |

- 9/20 是第二节点 τ 网格的数据驱动最优；
- 10/11 是干预时间线节点；

### 4.4 不确定性

- 14/21 天块 bootstrap 各 500/500 有效；
- `α0` 95% CI 约 `[0.12, 0.27]`；
- `u2` 95% CI 仍几乎覆盖 `[-0.5, 0.95]`；
- `R0late` 区间宽；
- `βh/βf/ν` 未独立估计；
- `ρh0` 从 0.3 到 0.5 会显著改变 `Rh`，但 `R0late` 变化较小。

## 6. 可识别性：为什么不能再硬调

### 6.1 `βf` 与 `ν`

`D` 没有观测，准稳态下 `D≈(μI+μQ Q)/ν`，感染项只识别

```text
βf/ν
```

所以 `βf` 和 `ν` 不能分别估；当前固定 `ν`、固定 `ρf0` 是必要的
情景化处理，不是“已经估出来”。

### 6.2 `βh` 与 `βc`

`I` 和 `Q` 高度共线，累计 C/M 主要识别组合；要分开 `βh/βc`，
需要 HCW 队列、医院获得性病例或医护人员人口数据。当前 `ρh0=0.4`
只能做 0.3–0.5 敏感性。

### 6.3 `ρ_rep` 与 `βc0`

累计 C 锚定后存在尺度交换；自由估计 0.885 训练更好但 holdout 更差，
所以主结果固定 1，自由估计只作敏感性。

### 6.4 `u2` 与 `R0late`

W41–W45 平台期信息有限，`u2` 在 `-0.5` 和 `0.95` 两端都有堆积；
Q2 的 14/21 天 bootstrap 仍覆盖整个允许范围。这是数据限制，不是
优化器没调好。

## 7. 与 ideas 里周尺度原版的关系

`ws/new/ideas/数据处理方案确定(1).md` 是**周尺度原版**（W25–W43，19 点）。
当前日尺度版继承了它的：

- 6 参数；
- `βc + ρh + ρf` 重参数化；
- 对数 NLS；
- CFR 软约束；
- MultiStart；
- 2/3 节点 AIC/BIC + τ 网格；
- 分块 bootstrap、profile、敏感性。

但**不采用**它的两处写法：

1. 不用 `new_*_adj` 累加还原累计序列（会破坏锚点）；
2. 不写 `ρ_rep = CFR_model/CFR_obs` 的恒等式（延迟/漏报不同，只做软约束）。

同时保留日尺度：

- 127 天拟合、15 天 holdout；
- 周表只做聚合校验；
- Q2 日度观测表保证所有模型输入日对齐。
