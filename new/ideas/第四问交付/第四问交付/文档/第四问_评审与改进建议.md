## 2. 主要问题（按严重程度）

### P1（最严重）：§4.4 策略比较用的是"纯假设"玩具矩阵，与真实数据脱节

```
K(u,v) = [[1.10u, 0.15v], [0.10v, 0.95u]]    ← "区域 A、B 无现实地理对应"
```

§4.1 费心整理出 Ituri 7,684 例、Nord-Kivu 2,737 例、占 94.38% 的真实分布，§4.4 却用两个虚构区域 + 拍脑袋的 1.10/0.95/0.15/0.10 做策略比较。**这是全文最大的硬伤**：Task 4 要求分析的是刚果（金）这次疫情，评委看到"策略结论来自假设矩阵"会直接质疑整个第四问的得分。

### P2（严重）：省际流动矩阵 H_ij 从头到尾"待识别"，连代理都没给

§4.2 定义了对的 P_ij、w_ij，然后说"定量映射待外部资料支持"。但 Task 4 **明确要求**"Inter-provincial population mobility matrices"——你不能因为缺真实 OD 就说"不做"。`A_PROBLEM_ADAPTATION.md` §3.7 本来规划了"引力/辐射模型 + m 敏感性"作为**情景代理**，这份文档反而回退了。

### P3（严重）：环形接种被降级成"本地传播乘数 = 0.9"

§4.4 说环围接种是"假设的本地传播乘数"，基线取 1，还承认"Tracker 累计接种数无法估计该乘数"。Task 4 明确要求"Ring vaccination strategies"，把它缩成一个 fudge factor 等于没建模。数据里其实有环的规模：W41 在管接触者 27,043 / 周新增 463 ≈ **58 人/例**，这足以支撑一个真实"环"模型。

### P4（中等）：边境管控与 §4.5 的跨境输入完全脱节

- `J_i(t)` 在 §4.2 是孤立的预设项，没和边境筛查挂钩；
- §4.4 的旅行限制只是一个 `v` 乘数，没用 `travellers_screened 276,403`、没建筛查覆盖率/灵敏度；
- §4.5 的肯尼亚 9 例/尼日利亚 1 例，和 §4.2 的 J_i、§4.4 的 v 没有数学上的衔接，三个部分各说各话。

### P5（中等）："局部→大规模"只给了 R_net>1 一个判据

题目要求"评估由局部暴发演变为大规模流行的条件"。§4.3 只给了 `R_net>1`（且自己正确指出它是必要非充分），缺 `A_PROBLEM_ADAPTATION.md` §3.7 里的另外两条：**R_local>1**（单省能否自持）和**输入通量足够**（每周传染性旅行者 × 目的地易感比例 > 阈值，否则即使 R_net>1 也会随机灭绝）。

### P6（中等）：§4.5 只用 Poisson，系统性高估了肯尼亚 9 例的风险

埃博拉传播是**超扩散**（overdispersion）的，用 Poisson（子代均匀）会高估"持续传播"概率。同均值 m=1.2 下：

| 子代分布 | 灭绝概率 q | 肯尼亚 9 例 P(持续) |
|---|---:|---:|
| Poisson（k=∞，本文所用） | 0.667 | **96.6%** |
| 负二项 k=1 | 0.833 | 81% |
| 负二项 k=0.5 | 0.887 | **66%** |

本文只报了 96.6% 这一最极端值，没有负二项敏感性，会误导结论。应至少报告 k∈{0.5, 1, ∞} 三档。

### P7（轻微）："六代累计新增"是任意截断

§4.4 用第 1–6 代期望和做指标，为什么是 6 代？应改为固定比较窗口内求解 ODE、报累计病例/死亡/R_net（§4.4 结尾自己都提到了，却当成"可选"）。

### P8（轻微）：卫生区层级完全没进模型

题目"8 省 66 卫生区"，§4.1 只把卫生区当计数，模型只到省层。省层建模本身可接受，但应说明为什么省层足够，或至少把 66/67 区作为展示/校验单元。

## 3. 改进方法（具体可落地）

### 改进 1：用引力/辐射模型把 H_ij 造出来（修 P2）

不要留"待识别"，直接构造情景代理：

```
M_ij = N_i·N_j / d_ij^γ          （i≠j，对角为 0；d_ij 用邻接或省会距离）
P_ij = M_ij / Σ_k M_kj           （列归一化：j 地居民在 i 地的停留份额）
H_ij = m_ref · w_ij · P_ij       （m_ref 基线流动强度，w_ij 有效接触权重）
```

- `m_ref` 取旧报告的 **1.5%/周** 为基线；`γ` 在 {1, 1.5, 2} 做敏感性；`w_ij` 初设全 1。
- 明确标注"情景代理，非真实 OD"，但**矩阵必须造出来并跑起来**，这是 Task 4 的硬性要求。

### 改进 2：把模型跑在真实 8 省上（修 P1，核心）

用 §4.1 的真实人口 + 病例分布：

1. 以 **Ituri 为初始疫源**（W25 或更早的种子），其余省易感；
2. 各省 β_i 从全国拟合值收缩得到（大省用点估计，稀疏省合并或给区间——§4.2 自己都写了这段，却没做）；
3. 看模型能否重现观测排序 **Ituri ≫ Nord-Kivu ≫ Haut-Uele > 其余**；
4. 即使没有真实 OD，这也是"给定重力情景下的条件估计"，**远好于玩具矩阵**。

策略比较也搬到 8 省上，输出下表（这才是 Task 4 该交的东西）：

| 策略 | R_net | 累计病例 | 累计死亡 | Ituri 外首例时间 | Nord-Kivu 峰值 |
|---|---:|---:|---:|---:|---:|
| 参考 | | | | | |
| 旅行+口岸 | | | | | |
| 区域协同 | | | | | |
| 环围接种 | | | | | |
| 组合 | | | | | |

### 改进 3：环形接种做成真实"环"（修 P3）

数据锚点：W41 有 27,043 在管接触者 / 463 周新增 ≈ **58 人/例**。

```
对每个新病例：识别 N_c≈58 名接触者 + N_cc 名接触者的接触者
环内易感者以覆盖率 c、效力 e、起效延迟 τ 被保护
等效：环内传播乘数 ≈ 1 − c·e·exp(−σ·τ)   （延迟期间已暴露者不获益）
```

参数 `c, e, τ` 无 BDBV 效力数据，做**情景**（e∈[0.3,0.9]），但机制是真实的环，不是拍脑袋的 0.9。

### 改进 4：边境管控与输入风险衔接（修 P4）

把 §4.2 的 `J_i`、§4.4 的 `v`、§4.5 的跨境病例连成一条链：

```
入境传染性旅行者数 = (跨境病例数) × (人均传染性旅行概率)
J_i ∝ 入境传染性旅行者 × (1 − 筛查灵敏度 × 覆盖率) × 本地易感比例
```

- 用 `travellers_screened 276,403` 给筛查规模锚点；
- 灵敏度/覆盖率做情景，直接算出"把肯尼亚 9 例挡在本地传播之外需要多高的筛查覆盖率"。

### 改进 5：补全"局部→大规模"三判据（修 P5）

```
① R_local,i > 1        单省能否自持（§4.3 的 K_ii）
② R_net > 1            网络能否扩张（§4.3 已做）
③ 输入通量足够         每周传染性旅行者 × 目的地易感比例 > 阈值，否则随机灭绝
```

③ 用改进 4 的输入风险直接给，就能回答"乌干达 20 例（已结束）为什么没点着"——因为通量/筛查使其随机灭绝了。

### 改进 6：§4.5 加负二项敏感性（修 P6）

```
q = (1 + m/k·(1−q))^(−k)
```

报三档 k∈{0.5, 1, ∞}，并明确结论：**Poisson 是风险上界，真实（超扩散）风险更低**；肯尼亚 9 例的"持续传播概率"应写成区间（约 66%–97%），而非 96.6% 一个点。

### 改进 7：策略比较改 ODE 全窗口输出（修 P7）

固定比较窗口（如 W25–W65），求解各策略的 8 省 ODE，报累计病例/死亡/R_net/首例时间，废弃"六代累计"。

### 改进 8：卫生区至少做展示/校验（修 P8）

省层建模 + 卫生区作为图 8 省下 66/67 区的分布展示，或在省级模型结果上叠加卫生区观测校验（卫生区死亡 4,394 ≠ 全国 4,887，死亡只在省层，卫生区只用病例）。
