# 第二问（Task 2）参数估计与数据使用方法：改进方案

> **定位**：本文是对 `A_PROBLEM_ADAPTATION.md` 第 3.4 / 3.5 / 4.3 / 5.5 节「数据口径」「参数估计」「观测方程」的**深化与修正**，专门回答一个可执行的问题——**拿到数据之后，每一个参数具体怎么算出来**。
>
> 相对适配文档的三处实质改进：
> 1. **给出「参数确定总表」**：每个参数标注「固定 / 数据锚定 / 待估 / 先验」四类确定方式，并给出计算公式，而不是只列一个参数名字。
> 2. **用重参数化打破共线**：把三个独立传播系数 `βc, βh, βf` 降为「1 个参考强度 `βc` + 2 个比例 `ρh, ρf`」，从根本上解决适配文档自己承认但没给出解法的「βh 与 α 共线」问题。
> 3. **把 `ρ_rep`（漏报率）与 CFR 联动**：解释粗病死率 48.6% 为什么高于历史 Bundibugyo 的 25–40%，并让固定参数满足自洽校验。

---

## 0. 三条核心原则（先记住）

1. **能固定的不拟合，能锚定的不自由估**。19–21 个周点、2 条累计曲线，信息量有限；每多一个自由参数，可识别性就崩一分。
2. **传播系数只估一个参考值 `βc`，其余用比例 `ρh, ρf` 表达**。`βh`、`βf` 无法从累计病例独立识别，硬估只会让误差在 `βf` 和 `ν` 之间互相吸收。
3. **固定参数必须自洽**：潜伏期、结局时间、CFR 三者要能对上，否则拟合出来的 `μ` 会和数据、术语表双重打架。

---

## 1. 参数确定总表（先看这一张）

| 参数 | 含义 | 确定方式 | 推荐值 / 先验 | 计算公式 / 依据 |
|:---:|---|:---:|:---:|---|
| `σ` | 潜伏→发病速率 | **固定（文献）** | 0.70 /周，[0.5, 0.9] | `σ = 7/T_inc`，T_inc≈10 天（Bundibugyo 5–12 天） |
| `γ, γQ` | 康复速率 | **固定（文献）** | 0.21 /周 | BDBV 中位病程 15–18 天 → `γ+μ≈0.42`；CFR≈50% 时 γ≈μ |
| `μ, μQ` | 疾病死亡速率 | **待估 + CFR 约束** | ≈0.14–0.24 /周 | `CFR = μ/(γ+μ)`；由死亡序列直接约束 |
| `ν` | 遗体安全处理速率 | **数据锚定（情景）** | 基线 3.5，加强 7 | `ν = 7/T_burial`，T_burial=2 天→1 天 |
| `α` | 隔离收治速率 | **待估 + 隔离比锚定** | ≈0.28 /周（需核实口径） | `α = (γQ+μQ)·隔离比/(1−隔离比)` |
| `βc0` | 社区传播参考强度 | **待估** | 拟合得到 | 匹配累计病例的增长率 |
| `ρh = βh/βc` | 医院/社区传播比 | **先验（下界证据）** | 0.3–0.5，强制 `<1` | 医护感染占比 269/全部≈2.4% 作下界 |
| `ρf = βf/βc` | 葬礼/社区传播比 | **先验（文献）** | 2.86–3.83 | Legrand et al. 2007 的 `κ`；做敏感性 |
| `ρ_rep` | 病例报告比例 | **待估 + 先验** | [0.5, 0.9] | 检测阳性率 13.3%、>80% 在已知接触者外发现 |
| `u1, u2` | 节点处干预降幅 | **待估** | [0, 1] | 节点位置由干预时间线固定，只估幅度 |

> 真正进优化器的自由参数只有 **6 个左右**：`βc0, u1, u2, α0, μ, ρ_rep`（`μQ`、`ρh` 视数据情况可放宽到 7–8 个，但必须配 profile likelihood）。

## 2. 拿到数据后的七步流程

### Step 0：数据校验（先做断言，再做任何拟合）

读入 `ebola_tracker/national_weekly_*.csv` 后，第一步不是画图，是**写死三个锚点断言**：

```
断言 W25 = 1,048 例 / 267 死
断言 W43 = 10,060 例 / 4,887 死   （题面「当前」口径）
断言 W45 = 10,990 例 / 5,354 死
```

过不了就说明口径读错了，往下做全错。然后建**数据质量标记表**，逐周标出：

| 周 | 异常 | 处理 |
|---|---|---|
| W26 | 国家行 WHO 手工读数，病例/死亡为空 | 周锚点取 2026-06-27 的 1,274/360 |
| W30 | 原始周新增 839 含 272/174 回顾补报 | 用 `new_*_adj`，不用原始差分 |
| W44 | 死亡差含 Ituri `+346/−269` 校正净效应 | 死亡不作真实新增 |
| 10/30–31 | harmonisation | 剔除 |
| 11/02 | reconstructed | 剔除 |

**结论：累计序列用调整后的 `new_*_adj` 累加；周新增只做诊断，不做拟合目标。**

### Step 1：固定参数（文献，一次算好不再变）

| 参数 | 计算式 | 代入 | 结果 | 敏感性范围 |
|:---:|---|:---:|:---:|:---:|
| `σ` | `7/T_inc` | `7/10` | **0.70** | 0.5–0.9（T_inc 8–14 天） |
| `γ, γQ` | `7/T_course·(1−CFR)` | `7/16·0.5` | **0.21** | 0.2–0.25 |
| `ν0` | `7/T_burial` | `7/2` | **3.5** | 3.5（2 天）– 7（1 天） |

### Step 2：数据锚定参数（直接从数据列算，先于拟合）

拿到数据后，先用下面几个关系把 `α`、`μ` 的「量级」钉住，再交给优化器在附近搜，避免优化器跑飞。

**(a) 隔离收治速率 `α` —— 由「隔离比」反推**

数据列：`etc_admitted`、活跃确诊、隔离比（约 39–40%）。

准稳态下有存量隔离比关系：

```
Q/(I+Q) = α / (α + γQ + μQ)
⟹  α = (γQ + μQ) · 隔离比 / (1 − 隔离比)
```

代入 `γQ+μQ ≈ 0.42`、隔离比 0.40：

```
α ≈ 0.42 × 0.40 / 0.60 ≈ 0.28 /周   ⟹   d_α ≈ 25 天
```

> ⚠️ **口径要核实**：旧实验报告拟合出 `α=1.244/周`（d_α≈5.6 天），与上式反推的 0.28 差近 4 倍。差异来自「隔离比 39–40%」到底指 `Q/(I+Q)` 存量比、还是别的口径。拿到 tracker 数据后，用 `etc_admitted` 与活跃确诊两列把「隔离比」定义对齐，再决定 α 的量级——这一步不核实，α 会直接带偏后续所有干预分析。

> 注意：`d_α≈15.5 天` 看起来慢，但这**与「约 2/3 死亡发生在社区」自洽**——很多感染者没等到隔离就死亡了。这不是随意设定，是数据本身给出的约束。若你的数据里隔离比更高（例如 45%），`α` 相应上修。

**(b) 死亡速率 `μ` —— 由死亡序列 + CFR 双重约束**

死亡序列 `dM/dt = μI + μQ·Q` 直接约束 `μ` 的量级。同时必须满足 CFR 自洽：

```
CFR_model = μ / (γ + μ)        （在 μQ=μ、γQ=γ 下）
```

而观测口径下：`CFR_obs = CFR_model / ρ_rep = 48.6%`。

⟹ **`μ` 的拟合值会随 `ρ_rep` 一起变**，这就是必须对 `ρ_rep` 做 profile likelihood 的原因。给三组参照：

| `ρ_rep` | 真实 CFR | 对应 `μ`（γ=0.21） |
|:---:|:---:|:---:|
| 1.0 | 48.6% | μ = 0.20 |
| 0.8 | 38.9% | μ = 0.14 |
| 0.7 | 34.0% | μ = 0.11 |

> 注意：`ρ_rep` 越低，`μ` 越小、`1/(γ+μ)` 越长；压到 0.7 以下时病程会超过 20 天，偏离 BDBV 的 15–18 天。这条「病程自洽」是 `ρ_rep` 的先验约束之一，最终取值交给 profile likelihood。

### Step 3：重参数化（关键一步，适配文档缺的）

**不要**把 `βc, βh, βf` 当三个自由参数。改成：

```
βc(t) = βc0 · [1 − u1·𝟙(t≥t1)] · [1 − u2·𝟙(t≥t2)]     （1 个参考强度 + 2 个节点降幅）
βh(t) = ρh · βc(t)                                       （比例，先验 0.3–0.5，<1）
βf(t) = ρf · βc(t)                                       （比例，先验 2.86–3.83）
```

- `ρh` 的下界证据：医护累计 269 例 ≈ 全部病例的 2.4%。如果医院传播真比社区强得多，医护占比会远高于此，因此 `ρh` 不宜超过 1。
- `ρf` 的文献依据：Legrand et al. (2007) 对 1995/2000 埃博拉的估计，葬礼传播约为社区的 2–3 倍（遗体病毒载量极高）。用 2.86–3.83 做基线，再扫 1–5 做敏感性。

这样传播参数从「3 自由」降到「1 自由 + 2 先验」，共线性被结构性地消掉。

### Step 4：待估参数拟合（对数尺度 NLS + MultiStart）

**观测方程（先写清楚再拟合）**：

```
C_obs(t) ≈ ρ_rep · C_model(t − d_c)
M_obs(t) ≈ M_model(t − d_m)        （死亡基本全报，ρ_M≈1）
C_model = I + Q + R + M；   dC_model/dt = σE
```

延迟核 `d_c, d_m` 取 0–1 周（几何/Gamma），先固定 0 试算，再放开。

**目标函数（对数尺度，替代适配文档 §3.5 的 5 段相对残差）**：

```
J(θ) = Σ_t [ log C_model(t) − log C_obs(t) ]²
     + λ · Σ_t [ log M_model(t) − log M_obs(t) ]²
     + 先验惩罚项
```

- 先验惩罚项：`ρh ∈ [0, 1]`、`ρ_rep ∈ [0.5, 0.9]`、`βc0 > 0`、`α0 > 0`；用对数参数化保证正值。
- 选 `λ`：死亡序列点数少、绝对量小，取 `λ≈1–3` 使其贡献与病例项相当；可用留出验证调 `λ`。
- 理由：疫情数据是乘性误差主导（1000→10000 跨度），对数空间误差近似同方差；相对残差会在早期小基数处被 floor 掩盖信息。

**优化器**：`fmincon` + `MultiStart`（≥8 初值）或差分进化。参数全部对数参数化。

**节点选择**：节点位置 `t1, t2` **由干预时间线固定**（PHEIC 5 月、疫苗分配 8-17、rollout 8-26、平台期 W41），只估降幅 `u1, u2`；再用 AIC/BIC 在「2 节点 vs 3 节点 vs 4 节点」之间选。

### Step 5：不确定性量化

| 手段 | 做法 | 回答的问题 |
|---|---|---|
| 残差 **block bootstrap** | 对周新增残差分块重采样（块长 2–3 周）再累加，500–1000 次 | 参数 95% CI、情景带 |
| **Profile likelihood** | 对 `ρ_rep, α, ρh` 各扫 15–20 个固定值，其余重估 | 这三个参数能否被数据识别 |
| 参数**相关矩阵** | 直接报 | 正面回答「βh 与 α 是否共线」 |
| 留出验证 | W44–W45 前向验证，报误差 | 过拟合与否 |

> **注意**：累计序列周间强自相关，普通 i.i.d. bootstrap 会低估方差，必须分块。

### Step 6：报告清单（Task 2 及格线）

1. 数据来源 + 两序列对照表（为什么选 tracker 而非旧口径）+ 质量标记表；
2. 预处理（`new_*_adj`、W44 校正、W26 手工读数）；
3. 观测方程（`ρ_rep` + 延迟核 + CFR 与漏报的联动说明）；
4. 估计方法（对数 NLS + MultiStart + 节点 AIC/BIC）；
5. 拟合优度（R²/RMSE + **残差自相关图** + 留出验证误差）；
6. 参数表（点估计 + 95% CI + 单位 + 确定方式）；
7. 可识别性（profile 图 + 相关矩阵 + 明确写「哪些是估的、哪些是假设的」）；
8. 不确定性来源逐条讨论。

## 3. 拟合算法骨架（MATLAB 伪代码）

```matlab
function fit = task2_fit(data, cfg)
    % data 来自 load_data(tracker)，含 C_obs, M_obs, flags, resp
    % --- 固定参数 ---
    p.sigma = 0.70;  p.gamma = 0.21;  p.gammaQ = 0.21;
    p.nu0   = 3.5;   p.rhoF   = 3.0;              % 文献 κ 取 3.0，敏感性扫 1–5

    % --- 待估参数（对数参数化，保证正值）---
    % theta = log([betaC0, alpha0, mu, rho_rep, u1, u2])
    lb = log([0.5, 0.05, 0.05, 0.5, 0.01, 0.01]);
    ub = log([3.0, 3.00, 1.00, 0.9, 0.95, 0.95]);

    obj = @(logtheta) neg_loglik(exp(logtheta), p, data);
    problem = createOptimProblem('fmincon','objective',obj, ...
        'x0', log([1.3, 0.28, 0.20, 0.75, 0.3, 0.3]), ...
        'lb', lb, 'ub', ub);
    ms = MultiStart('Display','iter');
    [theta_hat, ~] = run(ms, problem, 10);

    fit.theta = exp(theta_hat);
    fit.ci    = block_bootstrap(obj, theta_hat, data);   % 分块 bootstrap
    fit.prof  = profile_likelihood(obj, theta_hat, {'rho_rep','alpha'}); % profile
end

function v = neg_loglik(x, p, data)
    % x = [betaC0, alpha0, mu, rho_rep, u1, u2]
    p.betaC0=x(1); p.alpha0=x(2); p.mu=x(3); p.rho_rep=x(4);
    p.muQ=p.mu;                       % 默认 μQ=μ
    p.rhoH = 0.4;                     % 先验，见 Step 3
    p.betaC=@(t)x(1)*(1-x(5)*(t>=data.t1))*(1-x(6)*(t>=data.t2));
    p.betaH=@(t)p.rhoH*p.betaC(t);
    p.betaF=@(t)p.rhoF*p.betaC(t);
    out = simulate_seiqrd(p, data.t, data.y0);
    Cm = p.rho_rep * out.C;  Mm = out.M;
    v = sum((log(Cm)-log(data.C_obs)).^2) + 2*sum((log(Mm)-log(data.M_obs)).^2);
    % 先验惩罚
    v = v + 1e3 * max(0, p.rhoH - 1)^2;   % 强制 rhoH<1
end
```

> `simulate_seiqrd` 的 RHS 用第一问草稿的式 (2)：`λ = S/N·(βc(t)I + βh(t)Q + βf(t)D)`。节点 `data.t1, data.t2` 由干预时间线固定。

## 4. 最容易翻车的地方（拿数据后要盯住）

1. **别混用两套序列**：旧 1,193/535 与 tracker 1,048/267 只能选一套；选 tracker 并在正文说明理由。
2. **别用原始周新增拟合**：W30 的 839（含补报）会把峰值周判断错 3 周。
3. **别忽略 W44 死亡校正**：`+346/−269` 会让 `μ/μQ` 虚高。
4. **别让 `ρh ≥ 1`**：会得出「收治越多 R0 越高」的反直觉结论，必须强制 `<1` 或解释为净超额。
5. **别让 `ρ_rep` 自由漂**：它和 `μ` 有 trade-off，必须 profile，否则 CFR 与历史 25–40% 对不上。
6. **固定参数要过 CFR 自洽校验**：`μ/(γ+μ)` 落不到 40–49% 附近，说明 `γ` 或 `μ` 设错了。
