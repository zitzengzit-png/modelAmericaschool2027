## 必读的口径提醒

1. **初值分配与 Task 1/2 不同**：本管线用准稳态
   `I=inc/a`、`Q=αI/b`，6/21 为 `I0=137.6、Q0=360.0、R0=283.4`；
   国家模型是 `I0=421、Q0=360、R0=0`（`etc_admitted`）。这会影响早期传播与
   `R_net`，正文必须披露，不能声称“完全同一初值”。
2. `P` 是引力停留份额代理，**不是实测 OD**；`m=1.5%` 是情景参数。
3. `beta_mult=1` 是留出期模型筛选的结果，不是“省级传播力相同”的生物学结论。
4. `R_net=1.035` 是条件于当前 `P`、初值、`S/N` 的诊断，不是真实阈值，也不是预测。
5. 策略从 6/21 全程施加，回答“如果一开始就这样”；若要回答“现在加码 15 天”，
   需另做 10/25 重启版本，不能与本表直接比较。
6. 模型低估总量（8,234 vs 11,042），Nord-Kivu 尤其明显（579 vs 2,309）；
   `rho_rep=1` 与发病/确诊口径差是主要原因。
