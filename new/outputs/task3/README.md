## 必读的口径提醒

1. **无干预基线不是“现状冻结”**：`u2=−0.5` 表示 9/20 后 `βc` 继续上升；
   365 天结果是该反弹的外推，所有“避免病例”都相对于这条基线。
2. **干预是乘数，不是已估计的因果效应**；疫苗/PEP/治疗都不是仓室。
3. **MBP134 单用会增加病例**：它只降低 `μQ`（`0.03488→0.02093`），不提高 `γQ`，
   患者在 `Q` 停留更久，而 `Q` 仍通过医院通道 `βhQ` 传播。早期启动时病例 +33.8%、
   死亡 +8.8%；当前启动时病例 +13.9%、死亡 −2.0%。这是模型结构的结果，
   不是“治疗有害”的实证结论；B/D 组合中由隔离与院感控制抵消。
4. **瑞德西韦主值为 0 效果**（PALM 无死亡优势），S6b 与 B0 完全相同。
5. **S1 隔离效果小**：`α1=0.1790` 仅比 9/20 的 `α0=0.16979` 高 5.4%；
   若改用 P1 基线（`α0=0.30222`），必须重算 `α1`，否则会把“加强隔离”设反。
6. `T3_checks.csv` 的 5 项检查全部 PASS；`baseline_anchor_1109` 是 INFO（−1.69%），
   不是拟合失败。
7. **PEP 是全局乘数**：文档把 `φ_PEP=1−εωqp` 乘在整个 `Λ` 上，而不是只作用于
   43% 的可追踪暴露；因此 S7 的 54.6%/32.7% 应理解为上限性情景，不是“只保护
   接触者”的精确效果。
8. `T3_scenarios.csv` 的 `C_at_start` 是**题面报告值**（2,073 / 10,060），
   不是模型在该日的状态；模型状态见 `T3_trajectories.csv`。
