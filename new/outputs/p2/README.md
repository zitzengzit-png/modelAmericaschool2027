**解释**：`u2` 与 `R0late` 的区间几乎覆盖整个允许范围，且在 `u2=-0.5`

累计曲线稳定识别**。论文不能只报 `R0late=1.143`，必须同时给这个宽区间。

### 4. 固定假设敏感性（R0late / holdout MAPE）

| 情景 | R0late | holdout 病例 MAPE |
|---|---:|---:|
| 基线 | 1.1427 | 3.02% |
| `ρH0=0.30` | 1.1329 | 3.65% |
| `ρH0=0.50` | 1.1425 | 2.90% |
| `ρF0=2.86` | 1.1279 | 3.66% |
| `ρF0=3.83` | 1.1281 | 3.49% |
| `ν=0.35` | 1.1522 | 2.38% |
| `ν=0.70` | 1.1351 | 3.60% |
| `E0×0.5` | 1.1292 | 2.78% |
| `E0×1.5` | 1.2108 | 1.30% |
| `D0×0.5` | 1.1204 | 3.86% |
| `D0×1.5` | 1.1382 | 3.26% |

**结论**：`E0` 是最强的固定假设来源（R0late 变动约 0.08，holdout MAPE
从 2.78% 到 1.30%）；`ρH0`、`ν` 次之；`ρF0`、`D0` 影响较小。
`ρH0` 对 `Rh` 的分解影响很大（早期 0.518→0.700），但 `R0late` 几乎不变，
因为其他参数会补偿。因此 `Rh/Rf` 分解只能作为**条件于固定比例**的解释。

### 5. 模型比较

| 模型 | k | AIC | BIC | ΔAIC | holdout MAPE | R0late |
|---|---:|---:|---:|---:|---:|---:|
| 2 节点（允许反弹） | 5 | −1351.61 | −1333.93 | 0 | 3.02% | 1.1427 |
| 2 节点（`u2≥0`） | 5 | −1350.47 | −1332.78 | 1.14 | 6.04% | 0.7617 |
| 3 节点（7/13、8/17、10/11） | 6 | −1351.05 | −1329.82 | 0.57 | 2.54% | 1.1777 |

**结论**：AIC 选 2 节点反弹模型；3 节点 AIC 只差 0.57，但 BIC 差 4.10，
且 `u3` 落在下界 −0.5，说明第三个节点没有被稳定识别。严格 `u2≥0`
模型 holdout 明显变差（6.04%），支持“允许反弹”的结构选择，而不是
“越保守越好”。

## 使用提醒

1. 块 bootstrap 采用**条件 bootstrap**：初值 `E0/D0` 固定，残差按 7/14 天
   块重采样；它不覆盖初值不确定性，初值影响见敏感性表。
2. `ρRep` 在基线固定为 1，bootstrap 的 `rhoRep` 列恒为 1；其不确定性由
   profile 单独给出（自由估计 0.885）。
3. 所有区间都是**条件于**固定参数 `σ, γ, ν, ρH0, ρF0, ρM` 的；改变这些
   固定值会改变参数分布，见 `P2_sensitivity.csv`。
4. 正文引用时优先用 `P2_bootstrap_parameters.csv`、`P2_profile_ci.csv`、
   `P2_sensitivity.csv` 和 `P2_model_comparison.csv`，不要只引用单点。
