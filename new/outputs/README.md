## 注意

- P0（数据/配置）与 P1（模型拟合）分开，不要互相覆盖；
- P1 结果是**条件于** `ρh0=0.40、ρf0=3.00、ρRep=1` 的基线；这些值的敏感性在 P2 完成；
- P1 的 `u2` 为负（反弹），这是对“晚期平台期”的结构选择；
- 正文引用数字时，P0 用 `P0_summary.json`/`P0_checks.csv`，P1 用 `P1_metrics.json`/`P1_parameters.csv`。
