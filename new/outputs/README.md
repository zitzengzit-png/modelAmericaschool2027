## Q2 日尺度对齐输出（2026-11-19）

`q2/` 由 `ws/new/code/run_q2_aligned.m` 生成，采用第二问周尺度原版的
好方法，但保留日尺度数据：

- Q2 日度观测表：`q2_daily_observations_20261111.csv`（142 天，fit 127，
  holdout 15）；周表只做累计锚点校验；
- 6 参数、`βc+ρh+ρf` 重参数化、对数 NLS、CFR 软约束；
- MultiStart 8；固定 `ρ_rep=1` 基线 + 自由估计 0.885 敏感性；
- profile `α0, ρ_rep`；`ρh0` 做 0.3/0.4/0.5 三点敏感性；
- 2/3 节点 AIC/BIC + 第二节点 τ 网格；
- 14/21 天块 bootstrap 500 次。

主要结论：

- 10/11 固定 `ρ_rep=1`：R² 0.9964/0.9934，holdout MAPE 3.95%/1.23%，
  AIC −1352.64；
- 10/11 自由 `ρ_rep=0.885`：训练 AIC 更好但 holdout 5.52%/2.67%，**过拟合**；
- **9/20 固定 `ρ_rep=1`**：R² 0.9972/0.9942，holdout 1.91%/0.79%，
  AIC −1359.97、BIC −1342.28、`R0late=1.0300`；
- 3 节点 AIC 比 2 节点差 0.62、BIC 差 4.16，保留 2 节点；
- τ 网格显示第二节点 **2026-09-20** 优于 10/11 和 11/01；9/20 是数据驱动
  变点，10/11 是干预时间线节点，两者都应报告；
- 14/21 天块 bootstrap 各 500/500 有效；`α0` 的 95% CI 约 `[0.12, 0.27]`，
  `u2` 仍覆盖 `[-0.5, 0.95]`。
