## P2 不确定性输出（2026-11-19）

`p2/` 由 `ws/new/code/run_p2_uncertainty.m` 生成，共 24 个文件（23 个数据/图 + README）。详细说明见
`ws/new/outputs/p2/README.md`。核心结果：

- 7/14 天块 bootstrap 各 100/100 个有效 replicate；
- `u2` 与 `R0late` 的 95% 区间几乎覆盖整个允许范围（`R0late` 约
  [0.04, 1.24]），晚期反弹幅度不可稳定识别；
- `α0` profile 近似平坦，95% profile 区间为 (−∞,+∞)；`u1` 约
  [0.4315, 0.4815]；`ρRep` 自由估计 0.885，95% 区间 [0.885, 0.90]；
- 固定假设中 `E0` 影响最大（`R0late` 1.129–1.211），其次 `ρH0`、`ν`；
- AIC 选 2 节点反弹模型；3 节点 AIC 仅好 0.57、BIC 差 4.10，且 `u3`
  落在下界，未形成决定性改进。
