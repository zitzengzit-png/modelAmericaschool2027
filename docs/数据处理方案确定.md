## 2. 三方案点评（已更新到日尺度）

### 2.1 旧报告（骨架可用）

**做对的**：

- `σ=0.70、κ=3、ν=3.5` 全部文献固定；
- `γ=0.21` 有据（BDBV 中位病程 15–18 天）；
- CFR 软约束 `5·(CFR_model − 0.483)` 用稳定观测钉住 `μ`；
- 相对残差 + floor 防止早期小基数主导。

**缺的**：

- 窗口停在 W25–W41，题面 10,060/4,887 变成 holdout；
- 无数据质量处理；W30 补报会判错峰值；
- 无观测映射、无不确定性、无医院通道；
- 周尺度只有 17–21 个点。

### 2.2 适配方案（方向对，现已补日尺度）

**做对的**：切 tracker、质量标记、`ρ_rep`+延迟、bootstrap/profile、`state_at` 回溯、额外观测锚定；
第 11 节已把窗口、日表、日速率、日状态重建补齐。

**偏粗的**：

- 原文列 8–10 个待估参数，19–21 个周点识别不了；
- 相对残差 + Huber 对指数增长不如对数尺度稳；
- `ρ_rep` 与 CFR 没有联动；
- 原文是周尺度（已在第 11 节改为日）。

### 2.3 第二问方案（三处改进对，但周尺度写法要改）

**做对的**：

1. **重参数化**：`βc, βh, βf` → `βc + ρh + ρf`，结构性消 `βh/α` 共线；
2. **对数尺度目标**：乘性误差更对称；
3. **CFR 联动**：把漏报率和病死率绑在一起。

**需要修正的**：

- 原文按“19–21 个周点、2–3 周块 bootstrap”写，现已统一改为日；
- `α`、`μ` 在参数表里同时出现在“锚定”和“待估”，本文明确为“带锚定先验的待估参数”；
- `CFR_obs = CFR_model/ρ_rep` 当等式太强，本文改为**软约束**；
- `ρh/ρf` 固定比例会限制院感/安葬干预，本文允许时变；
- “累计序列用 `new_*_adj` 累加”会少算，本文改为累计序列直接取累计；
- 原文引用的 `第二问_参数确定与数据使用方法.md` 不在工作区。

## 3. 最终日尺度方案（照此执行）

### 3.1 数据准备：日表 + 日锚点 + 质量标记

**数据源**：`ws/new/data/ebola_tracker/national_daily_<tag>.csv`（2026-11-11 快照，SitRep 179）。

**窗口**：

- 日表：2026-06-21 至 2026-11-09，共 **142 天**；
- 拟合：2026-06-21 至 2026-10-25，共 **127 天**；
- 验证：2026-10-26 至 2026-11-09，共 **15 天**。

**日锚点（写死在加载层）**：

```text
2026-06-21 = 1,048 / 267
2026-10-25 = 10,060 / 4,887    ← 题面“当前”
2026-11-09 = 11,042 / 5,387    ← 最新日
```

周表 `national_weekly_<tag>.csv` 保留，但只做聚合校验：21 个周日锚点与日表
逐位一致（P0 已验证 0 差异）。

**质量标记表（日表 `flag`）**：

| 日期/周 | 异常 | 处理 |
|---|---|---|
| 6/26、7/16、7/28、7/29 | 当日无国家行 | 累计值 LOCF，`missing_day_locf` |
| 7/22、7/30 | catch-up（多天补报） | `special_report`；周诊断剔除 |
| 10/30–31 | harmonisation（Ituri 死亡 +346/−269） | `special_report`；10/31 还有 `negative_revision` |
| 11/02 | reconstructed（SitRep 142 缺失） | 保留，标记来源 |

**铁律（修正原文）**：

```text
累计水平 C(t), M(t) 直接用累计序列；
new_confirmed / new_deaths 只做日诊断；
new_*_adj 只做周诊断；
绝对不要用 new_*_adj 的累加去还原累计序列。
```

原因：`new_*_adj` 剔除了 catch-up/harmonisation，累加会低于累计值。核对：

- 确诊：W25→W45 累计差 **9,942**，`new_confirmed_adj` 合计 **9,452**，少 **490**；
- 死亡：累计差 **5,087**，`new_deaths_adj` 合计 **4,749**，少 **338**。

日表状态重建用 `new_confirmed` / `new_deaths`，并优先用 7 日滑动均值
`new_*_7d`；周表只用于回看和论文主表。

### 3.2 初值重建：`state_at_day()` 统一回溯

`Q0/R0` 不可观测，必须与所选日序列**同源**，禁止混搭旧周报的 `Q0=196`。

| 分量 | 日尺度方法 |
|---|---|
| `C(t), M(t)` | 直接取日累计值 |
| `Q(t)` | `etc_admitted(t)`；缺失时 `隔离比 × (C−M−R)` |
| `R(t)` | 累计康复；缺失沿用上一个有效值 |
| `I(t)` | `max(C − M − Q − R, 0)` |
| `E(t)` | 日新增（优先 7 日均值）/ `σ_day` |
| `D(t)` | 安葬延迟（天）× 日死亡（人/天） |
| `S(t)` | `N − E − I − Q − R − M` |

来自 P0 的边界说明：

- 2026-06-21 的 `E=0、D=0` 是首日边界（没有前一天），标记 `assumed_zero`；
- `R=0` 在 2026-08-09 之前是假设（tracker 到 W32 才发布康复）；
- 2026-07-14 正好是 2,073 例（C=2,073；7/13 为 2,011）。

### 3.3 参数四分类（消除“锚定又待估”的冲突）

| 类别 | 参数 | 值 / 范围 | 确定方式 |
|:---:|---|---|---|
| **固定** | `σ` | 0.10 /天 | 潜伏期约 10 天（=0.70/7） |
| | `γ=γQ` | 0.03 /天 | BDBV 病程 15–18 天（=0.21/7） |
| | `ν0` | 0.5 /天 | 安葬约 2 天（=3.5/7） |
| **带锚定先验的待估** | `α0` | 由隔离比给出先验 | `α` 仍进入拟合，锚定只作初值/先验；隔离比随时间变 |
| | `μ` | 由 CFR 给出先验 | `μ` 仍进入拟合，CFR 只作软约束 |
| **待估** | `βc0, u1, u2` | 正数 / [0,1] | 对数 NLS 拟合 |
| | `α0, μ, ρ_rep` | 正数 / [0.5,0.9] | 对数 NLS 拟合 |
| **先验** | `ρh0=βh0/βc0` | 0.3–0.5，强制 <1 | 医护占比 2.4% 下界 |
| | `ρf0=βf0/βc0` | 2.86–3.83 | 文献 κ |

**明确**：

- `α0`、`μ` 不是固定值，也不是“又锚定又自由”；它们是**带锚定先验的待估参数**；
- 锚定公式只用于给初值和先验，不作为恒等式；
- 如果数据支持，`α0`、`μ` 可以先固定做基线，再做敏感性；主结果仍建议估计。

### 3.4 重参数化（含 `ρh/ρf` 时变）

核心是把三个独立 `β` 压成“1 个参考 + 2 个比例”，从结构上消掉 `βh/α` 共线：

```text
βc(t) = βc0 · Π_k [1 − u_k · 1(t ≥ t_k)]
βh(t) = ρh(t) · βc(t)
βf(t) = ρf(t) · βc(t)

ρh(t) = ρh0 · [1 − u_H(t)]      % 院感控制
ρf(t) = ρf0 · [1 − u_F(t)]      % 安全安葬/葬礼干预
```

- `t_k` 用**日期**，不用周号：PHEIC（5/15，窗口前）、疫苗 rollout（8/17）、
  平台/安全事件（10/11）；
- 只估降幅 `u_k`，节点位置由干预时间线固定；AIC/BIC 在 2/3/4 节点间选；
- 另做一次 τ 网格搜索作敏感性，验证“变点是否落在干预日期附近”；
- `ρh/ρf` 允许随院感/安葬干预时变；如果缺少干预强度数据，可先固定
  `ρh0/ρf0`，再做敏感性，不能把“固定比例”当成机制结论。

### 3.5 额外观测锚定（日尺度对齐）

| 额外观测 | 日尺度处理 | 约束 |
|---|---|---|
| `etc_admitted` | 日值，缺失 LOCF | `Q` 量级与 `α`；注意它是 ETC 住院，不是确诊隔离 |
| `etc_occupancy` | 日值 | 收治容量/院感压力 |
| 医护累计 269/47 | 周序列（W29–W41） | `βh` 下界证据 |
| 社区死亡占比 0.595–0.674 | 日/周均可 | `μ` 与 `ν` 相对大小 |
| `contacts_seen_pct` | 日/周 | `φ_T` |
| 累计康复 869→2,951 | 日值（W32 起） | `γ, γQ` |
| `community_deaths` / `etc_deaths` | 7/13 起日值 | 葬礼/院内死亡分流 |

### 3.6 观测方程（日延迟 + CFR 软约束）

```text
C_obs(t) ≈ ρ_rep · (K_c * C_model)(t − d_c)
M_obs(t) ≈ ρ_M · (K_m * M_model)(t − d_m),   ρ_M ≈ 1
CFR_obs(t) = M_obs(t) / C_obs(t)
CFR_model(t) = M_model(t) / C_model(t)
```

- `d_c, d_m` 取 **0–7 天**，用离散 Gamma/几何核；
- `ρ_rep` 的先验来自检测阳性率 12.6%、>80% 新病例在已知接触者之外发现，
  建议范围 **0.5–0.9**；
- **CFR 只做软约束**：

```text
w_cfr · [CFR_model(T) − CFR_obs(T)]²
```

**不要**写成 `ρ_rep = CFR_model/CFR_obs` 的恒等式。原因：

1. 病例和死亡的报告延迟不同；
2. 病例漏报与死亡漏报程度不同（死亡更接近全报）；
3. CFR 随时间变化，不是常数；
4. 三通道模型下 CFR 还受 `μQ`、院内治疗、葬礼路径影响。

### 3.7 目标函数与优化

```text
J(θ) = Σ_t w_t [log C_model(t) − log C_obs(t)]²
     + λ · Σ_t [log M_model(t) − log M_obs(t)]²
     + w_cfr · [CFR_model(T) − CFR_obs(T)]²
     + 先验惩罚(ρh0<1, ρf0∈[2.86,3.83], ρ_rep∈[0.5,0.9])
```

- 日残差为主；另加一层“日模拟 → 周聚合”的残差作稳健性校验；
- `fmincon` + `MultiStart`（≥8 初值），参数对数化保证正值；
- 每日/每周权重 `w_t` 可按报告完整度调整，缺失日降权。

### 3.8 不确定性量化

| 手段 | 日尺度做法 | 回答 |
|---|---|---|
| 分块 bootstrap | 块长 **7–14 天**，500–1000 次 | 参数 95% CI、情景带 |
| profile likelihood | 只对 `ρ_rep, α0, ρh0` 各扫 15–20 值 | 能否识别 |
| 参数相关矩阵 | 直接报 | `βh` 与 `α` 是否仍共线 |
| 留出验证 | 2026-10-26..11-09（15 天） | 过拟合与否 |
| 周聚合校验 | 21 个周日锚点 | 日表与周表是否一致 |

> 日序列自相关强，普通 i.i.d. bootstrap 会低估方差；块长至少 7 天，
> 建议 7–14 天。

## 4. 为什么这套方案好

1. **127 个日点、6 个自由参数**：比 8–10 个参数稳；日点足够多，但仍保持
   保守，避免日度噪声把参数带偏。
2. **共线是结构性消掉的**：`βc + ρh + ρf`，不是“加先验硬压”；同时保留
   `ρh(t)/ρf(t)` 时变，院感和安葬干预才有落点。
3. **CFR 软联动**：用病死率这条相对稳定的观测约束漏报率，能解释
   “观测 CFR 48.6% 高于历史 Bungibugyo 25–40%”的数据矛盾；但不把
   `ρ_rep = CFR_model/CFR_obs` 当恒等式。
4. **日锚点 + 质量标记**：口径错在第一行就被拦住；日表可聚合回 21 个
   周日锚点，和题面/周表对得上。
5. **能固定就固定、能锚定就锚定、剩下的才拟合**：每条参数都有出处。
