## 建议阅读顺序

1. `A_PROBLEM_ADAPTATION.md` 第 0–4 节：先看新旧题差在哪里；
2. 第 5–8 节：旧模型要改哪些文件、怎么分阶段做；
3. 第 10 节：P0 周尺度初版记录；
4. **第 11 节：当前标准——全部用日**（日表、日状态重建、日速率、12 项验收）；
5. `数据处理方案确定.md`：Task 2 数据侧的执行方案（日尺度参数、观测方程、bootstrap/profile）；
6. 需要旧模型细节时，再查 `MODEL_ARCHITECTURE.md`。

## 与其他目录的关系

- 旧代码/旧数据/旧结果：`ws/old/`
- 新代码/新数据/P0 结果：`ws/new/`
- 本目录只放说明文档，不放代码或数据。

## 注意

- `MODEL_ARCHITECTURE.md` 描述的是**旧版**（W25–W41、7 省、无院内传播），
  其中的数值和结论不能直接用于新题；
- 新题的公式、参数和验收以 `A_PROBLEM_ADAPTATION.md` 为准。
