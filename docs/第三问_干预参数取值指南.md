# 第三问干预参数取值指南

> 定位：回答“反事实模型里每个干预的影响大小怎么自己定”。
> 本文不重新拟合 Q2；它规定**如何把干预情景写成可辩护的数值**。
> 配套：`ws/docs/第三问建模.md`、`ws/new/ideas/第三问干预思路_20261119.md`。

---

## 0. 一句话

干预数值 = **数据锚定的基线/覆盖率** + **文献或试验的效力** + **模型映射公式** + **低/中/高范围**。  
不是“从现有数据估出来”，也不是“随手拍一个数”。

---

## 1. 三个层次，不能混

| 层次 | 例子 | 来源 | 能不能自己定 |
|---|---|---|---|
| 基线参数 | `βc0, α0, μ, ν` | Q2 拟合 | 不能；用拟合值 |
| 当前覆盖率 | 追踪 79.2%、疫苗 21,866 剂、床位 1,539 | 数据 | 不能改，只能引用 |
| 干预效力/目标 | 疫苗效力 50–90%、隔离延迟 2–4 天 | 文献/试验/政策目标 | **必须自己定**，但要给依据和范围 |

反事实模型只改第三层及其映射后的参数路径，不动基线拟合。

## 2. 取值总流程

### Step 1：锁定基线

主基线用 Q2 9/20：

```text
βc0=0.11251 /天, u1=0.48919, u2=-0.50000
α0=0.16979 /天  → dα0=1/α0≈5.9 天
ν0=0.50 /天     → dν0=2 天
μ0=0.03488 /天
βh0=0.40 βc0, βf0=3.00 βc0
```

结构对照：Q2 10/11（`α0=0.22953`，`dα0≈4.4 天`）。  
两套基线不能混用；每个情景写明用哪套。

### Step 2：定覆盖率和目标人群

| 干预 | 数据锚 | 怎么用 |
|---|---|---|
| 追踪 | `contacts_to_follow=38,453`、`contacts_seen=30,444`（79.2%） | 当前覆盖率；目标 90%/95% |
| 疫苗 | `vaccinated_total=21,866` | 执行量，不是全国覆盖率；需目标人群分母 |
| 床位 | `etc_beds=1,539`，占用 58.2% | 收治容量约束 |
| HCW | 269 例/47 死 | 医院传播下界，不是 βh 效应 |
| ETC | `etc_admitted`、`etc_occupancy` | Q/α 的基线量级 |

### Step 3：定效力（efficacy）或执行强度

按证据强度选：

1. **试验/同类疫苗/药物**（最强）；
2. **同类埃博拉疫情的操作经验**；
3. **文献模型假设**；
4. **专家/保守情景**（最弱，必须标 C 级）。

### Step 4：映射到模型参数

不能用“病例下降 X%”直接减病例；要映射到参数：

| 干预 | 参数路径 | 公式 |
|---|---|---|
| 隔离 | `α(t)` | `α=1/dα` |
| 追踪 | `α_eff` | `d_eff=(1−φT)dα0+φT dT`，`α_eff=1/d_eff` |
| 安全葬礼 | `ν(t), βf(t)` | `ν=1/dν`，`κf=βf/ν` |
| 院感 | `βh(t)` | `βh_eff=βh0(1−φH)` |
| 疫苗 | `λ` | `λ_eff=λ(1−εV cV fV)` |
| 治疗 | `μ(t), μQ(t)` | `μ_eff=μ0(1−εT cT)` |
| PEP | `λ`（14 天） | `λ_eff=λ(1−εP cP)` |
| 健康教育 | `βc(t)` | `βc_eff=βc(1−φC)` |

### Step 5：低/中/高

- **中值**：文献范围的中点，或保守偏中；
- **低/高**：文献范围的下/上界；
- 没有文献：以中值为基准 ±50%，并标“C 级情景”；
- 所有比例限制在 [0,1]；延迟必须 >0；
- 不要用一个点值，至少三档。

### Step 6：跑反事实并做敏感性

- 基线复现 Q2；
- 单因素、组合、时机、追踪资源分别跑；
- 报告低/中/高下的病例、死亡、持续时间；
- 如果结论在范围内翻转，正文必须写。

## 3. 默认取值表（可直接作为第一版）

> 以下“中值”是**建模默认情景**，不是数据估计。  
> 基线：Q2 9/20。

| 干预 | 低 | 中 | 高 | 说明 |
|---|---:|---:|---:|---|
| 隔离延迟 `dα` | 4.0 天 | 3.0 天 | 2.0 天 | 基线 5.9 天；α 因子 1.47/1.96/2.95 |
| 追踪 `φT` | 0.78 | 0.90 | 0.95 | 当前 79.2%；`dT=1–2 天` |
| 安全葬礼 `dν` | 2.0 天 | 1.5 天 | 1.0 天 | ν=0.5/0.667/1.0 |
| 葬礼传播折减 `φB` | 30% | 40% | 50% | 与 dν 同向 |
| 院感折减 `φH` | 30% | 45% | 60% | HCW 只作下界 |
| 疫苗效力 `εV` | 0.50 | 0.70 | 0.90 | Bundibugyo 无获批苗 |
| 疫苗目标覆盖 `cV` | 0.30 | 0.50 | 0.80 | 目标人群，不是全国 |
| 治疗死亡折减 `εT` | 0.30 | 0.40 | 0.50 | 试验/同类药物 |
| 治疗覆盖 `cT` | 0.50 | 0.60 | 0.80 | 可及性 |
| PEP 效力 `εP` | 0.50 | 0.60 | 0.70 | 试验预设 |
| PEP 覆盖 `cP` | 0.60 | 0.75 | 0.90 | 接触者 |
| 健康教育 `φC` | 20% | 30% | 40% | 行为研究/情景 |

### 3.1 隔离的例子

```text
dα0 = 5.9 天
低：dα=4.0 → α 因子=5.9/4.0=1.47
中：dα=3.0 → 1.96
高：dα=2.0 → 2.95
```

不要把“隔离延迟减半”直接当成“病例减半”；要代入 ODE。

### 3.2 追踪的例子

```text
dα0=5.9, dT=1.5
φT=0.78 → d_eff=2.47 → α_eff=0.405
φT=0.90 → d_eff=1.94 → α_eff=0.515
φT=0.95 → d_eff=1.72 → α_eff=0.581
```

覆盖率来自数据；`dT` 是假设；效应是模型映射，不是因果估计。

### 3.3 安全葬礼的例子

```text
dν0=2 天, ν0=0.5
dν=1.5 → ν=0.667
dν=1.0 → ν=1.0
κf=βf/ν
κf_eff = κf0 × (1−φB)/(1+φN)
```

`φB` 是葬礼传播折减，`φN` 是 ν 提升比例；两者不能当作独立识别参数。

### 3.4 疫苗的例子

```text
λ_eff = λ × (1−εV cV fV)
```

- `cV` 是**目标人群**覆盖率（接触者/医护/疫区）；
- `fV` 是目标人群占总人口比例；
- 21,866 剂不能直接除以 38.4M 当全国覆盖率；
- 如果做全国接种，必须假设“产能达到目标覆盖率”，并标为情景。

### 3.5 治疗的例子

```text
μ_eff = μ0 × (1−εT cT)
μQ_eff = μQ0 × (1−εTQ cT)
```

只改病死率；不要把治疗同时当成传播阻断，除非另有依据。

### 3.6 PEP 的例子

```text
λ_eff = λ × (1−εP cP)，持续 14 天
```

PEP 是接触者短期保护，不是全民疫苗；覆盖 `cP` 是接触者覆盖。

## 4. 证据分级与文档写法

每个数值后面标等级：

| 等级 | 含义 | 例子 |
|---|---|---|
| A | 数据锚定 | `α0, βc0, μ`；contacts 79.2%；疫苗 21,866 |
| B | 文献/试验/同类疫情 | 疫苗效力 50–90%；治疗死亡折减 30–50% |
| C | 专家/纯情景 | 健康教育 βc −20~40%；冲突冲击 |

论文表格模板：

| 干预 | 参数 | 基线 | 低 | 中 | 高 | 证据等级 | 来源/依据 |
|---|---|---|---:|---:|---:|---|---|
| 追踪 | `φT` | 0.792 | 0.78 | 0.90 | 0.95 | A（覆盖）+B（效应） | contacts 表 + 追踪公式 |
| 疫苗 | `εV×cV` | — | 0.15 | 0.35 | 0.72 | B/C | 试验/情景 |
| 院感 | `φH` | — | 0.30 | 0.45 | 0.60 | B/C | 文献/院感经验 |

**不要写：**

- “我们估计疫苗效力为 70%”；
- “隔离使病例下降 30%”；
- “数据显示追踪 95% 可减少 X 例”。

**应该写：**

- “在疫苗效力 50–90%、目标覆盖 30–80% 的情景下……”
- “在追踪后隔离延迟 1–2 天的假设下……”
- “该结果是情景分析，不是因果估计。”

## 5. 现有数据能定量到什么程度

| 量 | 能否从数据定 |
|---|---|
| 基线 `βc0, α0, μ, ν` | 能（Q2） |
| 当前追踪覆盖率 79.2% | 能 |
| 疫苗执行量 21,866 | 能，但目标人群未知 |
| 床位/占用 | 能 |
| HCW 269/47 | 能，作下界 |
| 隔离延迟 5.9 天 | 由 `1/α0` 反推，是模型基线 |
| 疫苗/治疗/PEP 效力 | **不能**，无 RCT/个体数据 |
| 安全葬礼效应 | **不能**，无安葬延迟/安全葬礼数据 |
| 院感控制效应 | **不能**，只有 HCW 下界 |
| 健康教育效应 | **不能**，无行为调查 |

因此：**覆盖率和基线用 A 级；效力用 B/C 级；不要声称因果。**

## 6. 反事实情景的写法

### 6.1 单因素

- 其他干预关闭；
- 只改一个参数路径；
- 起点：2026-06-21（全窗口）和 2026-10-25（当前）各一套。

### 6.2 组合

- 效果相乘，不重复叠加同一机制；
- 追踪 90/95% 与隔离延迟不能同时取最大；
- 组合效应必须重跑 ODE，不能把单因素百分比相加。

### 6.3 时机

- 同一套效应，只改开始日期；
- 早期 7/14（2,073）vs 当前 10/25（10,060）；
- 不能把“早期已避免的病例”直接当成晚期结果。

### 6.4 追踪资源

```text
当前 contacts_to_follow=38,453, contacts_seen=30,444
90%：多随访 4,164 人
95%：多随访 6,086 人
additional_visits=additional_seen×21 天
tracers_needed=additional_seen/(10–20 人/天)
```

覆盖是数据；每人每天接触数是情景；传播效果用 `α_eff` 映射。

## 7. 常见错误

1. 把情景中值当数据估计；
2. 用全国人口当疫苗目标人群；
3. 把覆盖率当效力（`c` 与 `ε` 混）；
4. 把单因素百分比直接相加；
5. 把隔离延迟减半当成传播减半；
6. 同时独立改 `βf` 和 `ν`；
7. 用旧 Q4/W32 参数；
8. 只报中值，不报低/高；
9. 用 `R0late` 单点做政策结论；
10. 不标证据等级。

## 8. 一页检查表

- [ ] 基线明确（9/20 或 10/11）？
- [ ] 每个干预有低/中/高？
- [ ] 每个数值有证据等级 A/B/C？
- [ ] 覆盖率和效力分开？
- [ ] 目标人群分母明确？
- [ ] 映射到 α/βc/βh/ν/μ，而不是直接减病例？
- [ ] 组合重跑 ODE？
- [ ] 时机反事实同一效应？
- [ ] 追踪资源算式完整？
- [ ] 报告写“情景”，不写“因果”？
