## 1. 建模目标

在 Task 1 的三通道 SEIQRD 模型上，回答四件事：

1. 八类干预**单独实施**对累计病例、累计死亡、疫情持续时间的影响；
2. 多干预**组合**的效果与资源/成本 Pareto；
3. **干预时机**：2026-07-14（2,073 例）加速 vs 2026-10-25（10,060 例）当前；
4. 接触者随访率 **78%→90%/95%** 所需资源与传播减少量。

不把干预效果写成“已证实”；所有效果是**情景参数**，用区间和敏感性表达。

## 2. 基线模型

状态：

```text
S 易感者
E 潜伏者
I 有症状、未隔离感染者
Q 隔离收治者
R 康复者
D 尚未安全处理的传染性遗体
M 累计死亡（辅助量，D⊂M）
```

基线 ODE（无干预时）：

```text
Λ = S/N · [βc(t) I + βh(t) Q + βf(t) D]

dS/dt = −Λ
dE/dt = Λ − σE
dI/dt = σE − (α + γ + μ) I
dQ/dt = α I − (γQ + μQ) Q
dR/dt = γ I + γQ Q
dD/dt = μ I + μQ Q − ν D
dM/dt = μ I + μQ Q
C = I + Q + R + M
```

基线参数取 Q2：

- Q2 10/11：`βc0=0.11730`、`u1=0.44216`、`u2=-0.50000`、`α0=0.22953`、`μ=0.03481`；
- Q2 9/20：`βc0=0.11251`、`u1=0.48919`、`u2=-0.50000`、`α0=0.16979`、`μ=0.03488`；
- 固定：`σ=0.10/day`、`γ=γQ=0.03/day`、`ν=0.50/day`、`ρh0=0.40`、`ρf0=3.00`；
- `βh=ρh0 βc`、`βf=ρf0 βc`；
- `βc(t)=βc0(1-u1 1_{t≥t1})(1-u2 1_{t≥t2})`。

Task 3 只改这些参数的路径，不重新估计基线参数。

## 3. 干预 → 参数映射

### 3.1 一般形式

对每个干预 `k` 定义控制函数：

```text
c_k(t) = strength_k · ramp_k(t; t_start, τ_ramp) ∈ [0,1]
```

`ramp` 用 7 天线性/logistic 上升，避免参数瞬变。

总控制：

```text
βc(t) = βc_base(t) · (1 − φ_C c_C(t)) · (1 − ε_V c_V(t)) · (1 − ε_P c_P(t))
βh(t) = ρh0 βc_base(t) · (1 − φ_H c_H(t))
βf(t) = ρf0 βc_base(t) · (1 − φ_B c_B(t))
ν(t)  = ν0 · (1 + φ_N c_B(t))
α(t)  = α_base(t) · (1 + φ_I c_I(t)) · α_trace(φT)
μ(t)  = μ0 · (1 − ε_T c_T(t))
μQ(t) = μQ0 · (1 − ε_TQ c_T(t))
```

其中：

- `φ_C`：健康教育/社区接触下降；
- `ε_V`：疫苗效力，`c_V` 覆盖率；
- `ε_P`：PEP 效力，`c_P` 接触者覆盖；
- `φ_H`：院感控制对医院传播的折减；
- `φ_B`：安全葬礼对葬礼传播的折减；
- `φ_N`：安全葬礼对遗体处理速率的提升；
- `φ_I`：隔离强度；
- `α_trace(φT)`：追踪带来的有效隔离率；
- `ε_T/ε_TQ`：治疗对病死率的折减。

> 注意：`βf` 与 `ν` 不能独立识别；Task 3 把 `φ_B`、`φ_N` 作为**情景参数**，
> 同时报告有效葬礼项 `κf=βf/ν` 的变化，不声称二者独立识别。

### 3.2 八类干预的具体映射

| # | 干预 | 控制 | 参数变化 | 说明 |
|---|---|---|---|---|
| 1 | 患者隔离 | `c_I` | `α ↑`，`d_α=1/α ↓` | I→Q 加快 |
| 2 | 接触者追踪 | `φT` | `α_trace` ↑；可附 `φ_C` 小幅 | 追踪后隔离延迟 `dT=1` 天 |
| 3 | 安全葬礼 | `c_B` | `ν ↑`，`βf ↓` | 同时看 `κf=βf/ν` |
| 4 | 医院感染控制 | `c_H` | `βh ↓` | `ρh0` 或 `βh` 折减 |
| 5 | 疫苗接种 | `c_V` | `λ` 乘 `(1−ε_V c_V)` | 泄漏疫苗近似；环形/大规模覆盖 |
| 6 | MBP134/瑞德西韦 | `c_T` | `μ,μQ ↓` | 治疗覆盖与效力 |
| 7 | 奥贝德西韦 PEP | `c_P` | `λ` 乘 `(1−ε_P c_P)`，7–14 天 | 接触者短期保护 |
| 8 | 社区健康教育 | `c_C` | `βc ↓` | 接触率/行为下降 |

### 3.3 追踪公式

```text
d0 = 1/α_base(t)
dT = 1 天
d_eff = (1−φT)d0 + φT dT
α_trace(φT) = 1/d_eff
```

`φT=0.78` 为当前约 79%；`0.90/0.95` 为目标情景。

### 3.4 疫苗/PEP 的近似

不新增 `V` 仓室，用泄漏保护：

```text
λ_eff = λ · (1 − ε_V c_V(t)) · (1 − ε_P c_P(t))
```

这是 Task 3 的简化；Task 4 若要严格区分接种者/未接种者，再新增 `V` 仓室。

## 4. 干预后的完整方程

```text
Λ(t) = S/N · [βc(t)I + βh(t)Q + βf(t)D]
       · (1 − ε_V c_V(t)) · (1 − ε_P c_P(t))

dS/dt = −Λ(t)
dE/dt = Λ(t) − σE
dI/dt = σE − [α(t) + γ + μ(t)] I
dQ/dt = α(t)I − [γQ + μQ(t)] Q
dR/dt = γI + γQ Q
dD/dt = μ(t)I + μQ(t)Q − ν(t)D
dM/dt = μ(t)I + μQ(t)Q
C = I + Q + R + M
```

其中 `βc(t), βh(t), βf(t), α(t), ν(t), μ(t), μQ(t)` 由 §3 的控制函数给出。

### 4.1 瞬时有效再生数

```text
a(t) = α(t) + γ + μ(t)
b(t) = γQ + μQ(t)

Reff(t) = S(t)/N · [
    βc(t)/a(t)
  + α(t)βh(t)/(a(t)b(t))
  + (βf(t)/ν(t)) · (μ(t)/a(t) + α(t)μQ(t)/(a(t)b(t)))
] · (1 − ε_V c_V(t)) · (1 − ε_P c_P(t))
```

`Reff(t)<1` 只作为“当前传播强度低于替代阈值”的诊断，不是严格的全局灭绝判据。

### 4.2 状态重启

对 7/14 和 10/25 的时机反事实，用当前日表重建状态：

```text
y0 = state_at_day(data, start_date)
```

从 `start_date` 开始积分；`start_date` 之前的历史不重写，只把当时状态作为初值。

## 5. 四组情景

### 5.1 单因素

其他干预关闭，只开一个：

| 情景 | 控制 | 低值 | 高值 |
|---|---|---|---|
| 隔离 | `d_α` | 4 天 | 2 天 |
| 追踪 | `φT` | 0.78 | 0.90 / 0.95 |
| 安全葬礼 | `d_ν` | 2 天 | 1 天 |
| 院感控制 | `βh` 折减 | 30% | 60% |
| 疫苗 | 覆盖/效力 | 30%/50% | 80%/90% |
| 治疗 | 死亡风险折减/覆盖 | 30%/50% | 50%/80% |
| PEP | 效力/覆盖 | 50%/60% | 70%/90% |
| 健康教育 | `βc` 折减 | 20% | 40% |

每个情景跑两个起点：

- 2026-06-21（全窗口反事实）；
- 2026-10-25（当前阶段）。

### 5.2 组合

- 核心包：隔离 + 追踪 + 安全葬礼 + 院感；
- 核心包 + 疫苗；
- 核心包 + 治疗；
- 核心包 + PEP；
- 核心包 + 健康教育；
- 全包；
- 单项最强对照。

组合原则：效果相乘，不重复叠加同一机制；追踪 90/95% 与隔离延迟不能同时取最大。

### 5.3 时机

- 早期：2026-07-14（2,073 例）；
- 当前：2026-10-25（10,060 例）。

从各自状态重启，加同一套干预路径，比较：

1. 从各自干预起点到 horizon 的增量；
2. 从 7/14 起算的总病例/总死亡（统一口径）；
3. 持续时间、峰值、`Reff`。

### 5.4 追踪资源

当前快照：

```text
contacts_to_follow = 38,453
contacts_seen     = 30,444
≈ 79.2%
```

目标：

```text
90%：additional_seen ≈ 4,164
95%：additional_seen ≈ 6,086
```

资源：

```text
additional_visits = additional_seen × 21 天
tracers_needed = additional_seen / contacts_per_tracer_per_day
tracer_days = additional_visits / contacts_per_tracer_per_day
```

`contacts_per_tracer_per_day` 取 10–20；成本在 Task 6 乘单位成本。

## 6. 结果指标与持续时间

### 6.1 指标

- 累计病例 `C(T)`、累计死亡 `M(T)`；
- 相对基线避免的病例/死亡；
- 峰值日新增、峰值周新增；
- 峰值 `Q` 与 ETC 床位占用；
- `Reff(t)` 轨迹与终点；
- 资源量：接触者随访人数、tracer-days、疫苗剂次、治疗疗程、PEP 疗程；
- 持续时间。

### 6.2 持续时间定义

```text
结束条件：7 日新增病例 < 1，且之后连续 42 天无新增；
持续时间 = 干预起点 → 满足结束条件的日期。
```

若到 horizon（建议 2027-12-31）仍未满足，标记 `censored`，不伪造结束。

## 8. 数值算法

### 8.1 模拟器

新增 `simulate_q3_seiqrd.m`：

```text
输入：p（基线参数）、y0（7 状态初值）、tspan、控制结构 ctrl
输出：T, Y, C, M, Reff
```

- `ode15s`，`RelTol=1e-6`、`AbsTol=1e-8`、`MaxStep=1`；
- `NonNegative` 约束；
- 控制函数 `c_k(t)` 在 RHS 内按时间计算；
- 支持 `start_date` 重启。

### 8.2 情景循环

```text
for baseline in {Q2_10/11, Q2_9/20}
    for start in {2026-06-21, 2026-10-25}
        y0 = state_at_day(data, start)
        run baseline
        for scenario in single + combinations
            ctrl = make_controls(scenario, start)
            run simulate_q3_seiqrd
            compute outcomes
        end
    end
end
```

### 8.3 验证

- 先跑无干预基线，确认 2026-06-21..11-09 与 Q2 曲线一致；
- 再跑 7/14、10/25 重启的“无干预”分支，确认与基线连续；
- 最后跑干预情景。

### 8.4 事件检测

- 用日新增病例的 7 日滑动和；
- 找到最后一个 `7 日新增 ≥1` 的日期；
- 持续时间 = `last_case_date + 42 − start_date`；
- 若超过 horizon，标记 censored。

## 9. 不确定性

1. **基线不确定性**：Q2 10/11 与 9/20 两套参数；Q2 bootstrap 区间；
2. **干预效果不确定性**：每个 `φ/ε` 取低/中/高，做 OAT/tornado；
3. **组合不确定性**：LHS 抽样 100–200 组，报告病例/持续时间分布；
4. **结构不确定性**：追踪/疫苗/PEP 的映射是近似，换映射做对照；
5. **资源不确定性**：tracers/contact、疫苗效力、治疗覆盖。

不要在 Task 3 重新做全局 Sobol；那属于 Task 5。

## 11. 局限与论文写法

1. **干预效果不是本题数据估计**：写“情景假设 + 文献范围”，不写“已证实”。
2. **`βh/βf/ν` 仍固定/敏感性**：Task 3 只做参数路径，不声称独立识别。
3. **疫苗/PEP 用泄漏近似**：没有新增 V 仓室；Task 4 可升级。
4. **持续时间依赖结束定义**：必须同时报告 42 天倒计时与 censored。
5. **国家层面**：Task 3 先做全国；省级/跨境在 Task 4。
6. **组合效应非独立**：不能把单因素效果简单相加，必须重跑 ODE。
