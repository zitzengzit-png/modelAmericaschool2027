# 第五问：敏感性、不确定性与政策稳健性建模

> 定位：Task 5 的正式建模文档。本文不重新拟合主模型，而是在
> Q2 日尺度模型与 Q3 干预情景上做敏感性、结构不确定性和政策稳健性。
>
> 重要：本文第 2 节专门列出**与前面工作的冲突和当前无法解决的问题**。
> 不把不可识别参数伪装成可采样参数，也不把条件 bootstrap 当成完整后验。

---

## 0. 一句话结论

Task 5 不是“再做一次 OAT”，而是四层：

```text
参数层：Morris → LHS/PRCC → Sobol
结构层：模型变体 → 排名/结论是否翻转
情景层：数据/病毒/冲突/行为 → 政策是否稳健
政策层：Q3 干预包 → 排名、regret、阈值
```

同时必须承认：

- `βh/βf/ν` 不可独立识别，只能做结构情景；
- `u2/R0late` 弱识别，不能只报 Sobol 指数；
- Q2 9/20 与 10/11 是两套不同拟合，不能混成一个“不确定性分布”；
- Q3 干预效果是情景假设，Task 5 的政策不确定性继承这些假设；
- 省级日数据不平衡、无流动数据，Task 5 先做国家层面；
- 成本数据未齐，Task 5 只做健康结果/资源排名，成本留给 Task 6。

## 2. 与前面工作的冲突和未解决问题

这一节必须和论文正文一起看；否则后面的 Sobol/政策排名会被误读。

### 2.1 Task 1 模型：三通道但不可全识别

- 模型有 `βc, βh, βf` 三通道，但数据只有累计 C/M 和少量 Q/R/死亡；
- `βh` 与 `βc` 共线，`βf` 与 `ν` 只能识别比值；
- 当前固定 `ρh0=0.40`、`ρf0=3.00`、`ν=0.50`；
- **冲突**：如果把 `βh/βf/ν` 当独立 Sobol 因子，会得到看似精确、实则无意义的排名；
- **处理**：它们是结构层情景，不是参数层因子。

### 2.2 Task 2 拟合：两套基线不能混

- P1 10/11（3 初值）：holdout 3.02%/0.57%；
- Q2 10/11（8 初值）：holdout 3.95%/1.23%；
- Q2 9/20（8 初值）：holdout 1.91%/0.79%，AIC 更好；
- **冲突**：三套都是“合理拟合”，但参数不同；把它们混成一个分布会低估结构不确定性；
- **处理**：9/20 作为主拟合；10/11 作为干预时间线结构变体；P1 只作历史基线，不参与 Task 5 主抽样。

### 2.3 Q2 bootstrap 是条件 bootstrap

- 500 次 14/21 天块 bootstrap 是在固定 `ρh0/ρf0/ν`、固定模型结构、固定初值下做的；
- 它覆盖的是“残差重采样 + 参数重估”的条件不确定性，不是完整后验；
- **冲突**：不能把它当成“所有不确定性”的分布，也不能用它给 `βh/βf/ν` 造 CI；
- **处理**：参数层用它做联合输入；结构层单独做变体。

### 2.4 `u2`/`R0late` 弱识别

- `u2` 的 95% 区间几乎覆盖 `[-0.5,0.95]`；
- `R0late` 区间宽；
- **冲突**：Sobol 对 `u2` 的指数可能很高，但不代表“可政策调控”；
- **处理**：`u2` 不进入主 Sobol；用 9/20 vs 10/11 vs 11/01 结构情景；
- 正文只报 `R0late` 区间/情景，不报单点。

### 2.5 `α0` 弱识别

- Q2 `α0` profile 左端截断；
- **冲突**：参数层 Sobol 会把 `α0` 当成连续因子，但其分布不对称；
- **处理**：用 bootstrap/profile 的经验分布，不用对称正态/均匀；报告 censored。

### 2.6 Q3 干预效果是情景假设

- 疫苗效力、治疗死亡折减、PEP 效力、追踪效果都不是本题数据估计；
- **冲突**：Task 5 的“政策排名”会继承这些假设，不能写成“数据证明某干预最好”；
- **处理**：政策层明确标“情景假设 + 区间”，并用 regret/阈值而不是单点排名。

### 2.7 Q3 代码尚未实现

- 目前只有 Q3 建模文档和情景清单；
- **冲突**：Task 5 的政策层依赖 Q3 模拟器；
- **处理**：先做参数层/结构层（只依赖 Q2），Q3 完成后再做政策层；文档中明确依赖顺序。

### 2.8 省级/空间数据不平衡

- 只有 3 个省覆盖完整 142 天；
- 卫生区/跨境只有快照；无流动数据；
- **冲突**：不能做“8 省全窗口日尺度”的敏感性；
- **处理**：Task 5 先做国家层面；空间敏感性留到 Task 4 后，且只用缺失掩码/短窗口。

### 2.9 成本数据未齐

- Task 6 才做成本/资金缺口；
- **冲突**：Task 5 不能给“成本最小”的政策排名；
- **处理**：只做健康结果/资源量排名；成本作为后续维度。

### 2.10 与周尺度 ideas 文件的冲突

- `数据处理方案确定(1).md` 是周尺度原版，且有两处写法与当前日尺度标准冲突：
  1. 用 `new_*_adj` 累加还原累计序列（会破坏锚点）；
  2. `ρ_rep = CFR_model/CFR_obs` 恒等式（当前只做软约束）；
- **处理**：Task 5 沿用当前日尺度规则，不回到周尺度；这两条不进入 Task 5。

## 3. 基线、输出与时间口径

### 3.1 基线

- **主基线**：Q2 9/20（数据驱动最优 τ）；
- **结构对照**：Q2 10/11（干预时间线）；
- **历史基线**：P1 10/11 只作对照，不进入主抽样。

基线参数固定：

```text
σ=0.10/day, γ=γQ=0.03/day, ν=0.50/day,
ρh0=0.40, ρf0=3.00, ρM=1
```

### 3.2 输出

| 输出 | 定义 |
|---|---|
| `Y_cases` | 2027-06-30 累计病例 |
| `Y_deaths` | 2027-06-30 累计死亡 |


到 horizon 未结束：`censored=1`，不要伪造结束。

## 4. 参数层：Morris → LHS/PRCC → Sobol

### 4.1 进入参数层的因子

只放**可识别/可解释**的连续因子：

| 因子 | 范围 | 来源 |
|---|---|---|
| `βc0` | 0.10–0.14 | Q2 bootstrap |
| `u1` | 0.30–0.60 | Q2 bootstrap |
| `α0` | 0.12–0.27 | Q2 profile/bootstrap |
| `μ` | 0.031–0.038 | Q2 bootstrap |
| `E0` | ±50% | 初值假设 |
| `D0` | ±50% | 初值假设 |
| `delay` | 0–7 天 | 报告延迟 |

可选（单独标注为“报告/数据因子”）：

- `ρ_rep`：0.5–1.0，但基线固定 1，自由 0.885 只作结构变体；
- `σ`、`γ`：0.07–0.13、0.02–0.05，作为病毒株情景，不进入主 Sobol。

**不进入参数层**：

- `u2`（结构：9/20 vs 10/11 vs 11/01）；
- `ρh0/ρf0/ν`（结构：0.3–0.5 / 2.86–3.83 / 0.35–0.7）；
- `βh/βf` 单独值（不可识别）；
- 省级/流动参数（Task 4）。

### 4.2 联合抽样，不要独立均匀

Q2 bootstrap 已经给出 `βc0,u1,α0,μ` 的联合样本。优先：

1. 直接使用 500 组 bootstrap 参数；
2. 对 `E0/D0/delay` 做 LHS；
3. 用 rank correlation/copula 保留 `βc0-u1`、`α0-μ` 的相关性；
4. 不要对四个参数独立均匀采样。

### 4.3 方法

1. **Morris**：7–10 因子，20 条轨迹，计算 `μ*` 和 `σ`；
2. **LHS**：1000–2000 组，计算 PRCC（秩变换 + 残差回归）；
3. **Sobol**：取前 5–6 个因子，Saltelli `N=512/1024`；
4. 如果运行量大，先用 LHS 训练 GP/多项式混沌代理，再在代理上算 Sobol；
5. 每个指数给 bootstrap CI。

### 4.4 解释规则

- PRCC/Sobol 只说明“在给定范围和模型结构下”的贡献；
- 不能把 `u2` 的高指数解释为“可政策调控”；
- 如果排名在 bootstrap 下不稳定，正文只报“前几名集合”，不报精确名次。

## 5. 结构层：模型变体

对每个变体跑 200–500 组 LHS 子样本，比较：

- 参数排名；
- 政策包排名；
- `Y_cases/Y_deaths/Y_duration` 分布。

| 变体 | 取值 | 目的 |
|---|---|---|
| 节点数 | 2 vs 3 | 结构过拟合/欠拟合 |
| 第二节点 | 9/20 vs 10/11 vs 11/01 | 数据驱动 vs 干预时间线 |
| `ρ_rep` | 固定 1 vs 自由 0.885 | 报告率假设 |
| `ρh0` | 0.30 / 0.40 / 0.50 | 医院通道 |
| `ρf0` | 2.86 / 3.00 / 3.83 | 葬礼通道 |
| `ν` | 0.35 / 0.50 / 0.70 | 安全葬礼 |
| 医院通道 | `βh=0` vs `ρh0=0.4` | 三通道是否必要 |
| 观测延迟 | 0 vs 7 天 | 报告延迟 |
| 疫苗/PEP | 泄漏近似 vs V 仓室（若实现） | 干预结构 |

**规则**：结构变体不取平均；报告“哪些结论翻转”。

## 6. 情景层：数据/病毒/冲突/行为

| 情景 | 路径 | 参数 |
|---|---|---|
| 数据质量 | 报告率 0.5–1.0；延迟 0–7 天 | `ρ_rep`, delay |
| 病毒株 | σ/γ/μ、CFR、传播力 | `σ,γ,μ,βc0` |
| 冲突 | βc 短期 +20–50%，持续 4–12 周；α/ν/疫苗覆盖下降 | 时间路径 |
| 行为 | βc ±20–40%；葬礼/接触变化 | `βc`, `βf/ν` |
| 空间（后续） | `m=0.5–5%/周`；边境 0–100% | Task 4 |

情景是**时间路径**，不是随机噪声：

```text
冲击(t) = 阶跃 × exp(-(t-t0)/τ_recover)
```

每个情景报告 `Y_cases/Y_deaths/Y_duration` 与政策排名。

## 7. 政策层：Q3 干预包的稳健性

### 7.1 政策包

- 核心包：隔离 + 追踪 + 安全葬礼 + 院感；
- 核心包 + 疫苗；
- 核心包 + 治疗；
- 核心包 + PEP；
- 全包；
- 单项最强。

### 7.2 排名

在每个参数/结构/情景样本下计算：

```text
cases_averted, deaths_averted, duration, resource
```

得到 package 排名；报告：

- 每个包“排名第一”的概率；
- 平均排名；
- 最差情景排名。

### 7.3 Regret

```text
regret(p, s) = best_outcome(s) − outcome(p, s)
```

选择：

- minimax regret（最坏情景最不后悔）；
- 平均 regret 最小；
- 若两者冲突，正文并列。

### 7.4 阈值

- `Reff=1` 所需追踪覆盖率/疫苗效力/治疗覆盖；
- 保持核心包优于单项的最小疫苗效力；
- 冲突导致 `βc` 上升多少会让结论翻转。

**成本**：Task 5 只做资源量；成本/资金缺口在 Task 6。

## 9. 结论边界（必须写进论文）

1. **参数层**只对可识别参数做 Sobol；`βh/βf/ν` 是结构层，不是独立参数；
2. **bootstrap 是条件 bootstrap**，不是完整后验；
3. **9/20 与 10/11** 是两套拟合，不混成一个分布；
4. **Q3 干预效果**是情景假设，Task 5 的政策排名继承这个假设；
5. **省级/跨境**数据不足，Task 5 先做国家；空间敏感性在 Task 4 后；
6. **成本**未齐，Task 5 只做健康结果/资源；
7. **Sobol 指数**依赖范围和模型结构，不能脱离上下文解释；
8. **不可识别参数**不能用 Sobol“洗白”。
