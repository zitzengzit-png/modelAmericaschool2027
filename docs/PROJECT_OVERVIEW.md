## 3. 当前主模型（Task 1 / Task 2）：日尺度三通道 SEIQRD + M

### 3.1 状态与方程

状态：`S, E, I, Q, R, D`，外加辅助累计死亡 `M`。`D ⊂ M`，**不能**把 `D` 再加进总人口。
`C = I + Q + R + M`，且 `dC/dt = σE`。

```text
Λ(t) = S/N · [ βc(t)·I + βh(t)·Q + βf(t)·D ]

dS/dt = −Λ
dE/dt =  Λ − σE
dI/dt =  σE − (α + γ + μ)I
dQ/dt =  αI − (γQ + μQ)Q
dR/dt =  γI + γQ·Q
dD/dt =  μI + μQ·Q − νD
dM/dt =  μI + μQ·Q
```

守恒：`S+E+I+Q+R+M = N`；相容：`0 ≤ D ≤ M`。
实现：`ws/new/code/simulate_daily_seiqrd.m`（`ode15s`，`NonNegative`，`MaxStep=1`）。

### 3.2 三条通道的参数化（这是本项目的核心简化）

```text
βh(t) = ρh0 · βc(t)      ρh0 = 0.40
βf(t) = ρf0 · βc(t)      ρf0 = 3.00
βc(t) = βc0 · ∏_i (1 − u_i · 1(t ≥ t_i))
```

- 只有 `βc(t)` 是时变的；`α`、`ν` 在实际拟合中是常数（Task 1 方程允许它们时变，但无数据支撑）。
- `ρh0/ρf0/ν` 是**情景/文献值**，不是数据独立识别的参数。
- 节点实现：`ws/new/code/make_beta_fun_multi.m`，可任意节点数，允许 `u_i < 0`（表示反弹/放松）。

### 3.3 R0 与 Reff（下一代矩阵，Task 1 式 (8)–(9)）

```text
a = α + γ + μ,  b = γQ + μQ

R0 = βc/a + α·βh/(a·b) + (βf/ν)·( μ/a + α·μQ/(a·b) )
   =  Rc   +      Rh      +            Rf

Reff(t) = (S(t)/N) · 同结构（用 βc(t)、α(t)、ν(t)）
```

数值校验（`task1_checks.m`，6/6 PASS）：
legacy 闭式 = 数值谱半径 = `1.355789887 / 0.884312117`；
新版 `1.341443500`（早）/ `1.142720773`（晚），通道分解 `Rc 0.3314 + Rh 0.6178 + Rf 0.3922`。

### 3.4 固定参数与初值

| 参数 | 日值 | 说明 |
|---|---:|---|
| `σ` | 0.10 | 周值 0.70/7 |
| `γ = γQ` | 0.03 | 周值 0.21/7 |
| `ν` | 0.50 | 周值 3.5/7，平均 2 天 |
| `ρh0` | 0.40 | 医院/社区等效比 |
| `ρf0` | 3.00 | 葬礼/社区等效比 |
| `ρM` | 1.00 | 死亡报告比 |

初值（`daily_initial_state.m`）：`C0=1,048`、`M0=267`、`Q0=360`、`R0=0`、`I0=421`；
`E0 = 首周日均新增/σ ≈ 322.9`、`D0 = 2 × 首周日均死亡 ≈ 26.6`（warm start，P0 首日的 0 是边界值）。

| 项目 | 结果 |
|---|---|

| `R0late` 95% CI | 约 `[0.04, 1.24]`（P2）→ 不能只报单点 |

| 固定假设敏感性 | `E0` 影响最大（`R0late` 1.129–1.211），`ρH0`、`ν` 次之 |

**结构性不可识别（必须在论文披露）**：
`βf` 与 `ν` 只能识别比值 `βf/ν`；`βh` 与 `βc` 因 `I/Q` 共线；`ρ_rep` 与 `βc0` 存在尺度交换。
解决办法只能是加数据（HCW 队列、医院获得性病例、安葬时滞）或改参数化，**不是继续调参**。

## 13. 模型谱系对比：Task 3 / Task 4 交付版 / 当前主模型

### 13.1 Task 3 实现 vs 当前国家模型（Q2/P1）

`ideas/任务三_...md` 与 `docs/第三问建模.md` 字节完全相同（MD5 一致），是同一份文档。

| 维度 | 当前模型（`simulate_daily_seiqrd.m`） | Task 3 文档 | 差异性质 |
|---|---|---|---|
| 状态/方程 | `S,E,I,Q,R,D,M`，三通道 | 完全相同 | 无 |
| `βc(t)` | 2 节点分段常数 | 相同节点 + 干预乘数 | 控制层 |
| `α` | 常数（Q2 9/20 = 0.16979；P1 = 0.30222） | `α(t)=α0+(α1−α0)g_iso`，`α1=0.1790` | 时变化 |
| `ν` | 0.50 | `ν(t)=0.50+(1.00−0.50)g_burial` | 时变化 |
| `μQ` | `=μ` 常数 | `μQ(t)=μQ[1−η·c(t)]`（治疗） | 时变化 |
| `βc` | 原值 | `×φ_CT(q)×φ_CE,c(t)` | 干预乘数 |
| `βh` | `ρh0βc` | `×[1−η_HIC·g_HIC]` | 干预乘数 |
| `βf` | `ρf0βc` | `×φ_CE,f(t)` | 干预乘数 |
| `Λ` | `βcI+βhQ+βfD` | `×φ_V(t)×φ_PEP(t)` | 干预乘数 |
| 视界 | 142 天（数据到 11/09） | **365 天**（到 2027-06） | 外推 |
| 时点 | 拟合节点 8/17、9/20 | 干预启动 **7/14** 与 **10/25** | 反事实 |
| 输出 | `C,M,Reff` | +峰值、`T_end`、`R_C/R_M`、资源 | 新指标 |
| 估计 | 数据拟合 | **不重拟合**，效果值为文献/情景 | 条件情景 |
| 代码 | 有 | `task3_*.m`（6 个）+ `run_task3_interventions.m` | 已实现 |

**三条必须注意的口径问题**：

1. **`α1=0.1790` 只对 9/20 基线是“加强隔离”**（`α0=0.16979`，仅 +5.4%）。对 P1 基线
   （`α0=0.30222`）它是 −41%，会把隔离干预设反；文档只给了 10/11 的修正值
   `α1,alt=0.2685`，没有覆盖 P1。
2. **无干预基线不是“现状冻结”**：`u2=−0.5` 表示 9/20 后 `βc` 继续上升，Task 3 把它外推到
   2027 年 6 月；所有“避免病例数”都相对于这条反弹基线。
3. **疫苗/PEP/治疗都不是仓室**，只是乘数；PEP 与追踪的乘数相乘，存在效果重叠。
