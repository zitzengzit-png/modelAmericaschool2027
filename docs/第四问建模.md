## 2. 8 省 SEIQRD 元群模型

### 2.1 状态

每个省 `i=1..8`：

```text
S_i, E_i, I_i, Q_i, R_i, D_i, M_i
C_i = I_i + Q_i + R_i + M_i
```

### 2.2 传播项

```text
βc,i(t) = beta_mult_i · βc0 (1-u1 1_{t≥t1})(1-u2 1_{t≥t2})
βh,i(t) = ρh0 βc,i(t)
βf,i(t) = ρf0 βc,i(t)

Λ_i = S_i/N_i · [βc,i I_i + βh,i Q_i + βf,i D_i]
      + S_i/N_i · Σ_{j≠i} H_ij I_j + J_i(t)
H_ij = βc,j(t) · w_ij · P_ij
```

- `P_ij`：j 地居民在 i 地停留的时间份额，列随机（`Σ_i P_ij=1`）；
- `w_ij`：有效接触权重，基线 1；
- `J_i`：外源输入；境内拟合取 0，跨境风险单独做分支过程；
- 医院/葬礼项只保留本地，不跨省。

### 2.3 ODE

```text
dS_i/dt = −Λ_i
dE_i/dt = Λ_i − σE_i
dI_i/dt = σE_i − (α+γ+μ)I_i
dQ_i/dt = αI_i − (γQ+μQ)Q_i
dR_i/dt = γI_i + γQ Q_i
dD_i/dt = μI_i + μQ Q_i − νD_i
dM_i/dt = μI_i + μQ Q_i
```

守恒：`S_i+E_i+I_i+Q_i+R_i+M_i=N_i`；`0≤D_i≤M_i`。

### 2.4 Q2 参数

主基线：Q2 9/20：

```text
βc0=0.11251, u1=0.48919, u2=-0.50000,
α=0.16979, μ=0.03488,
σ=0.10, γ=γQ=0.03, ν=0.50,
ρh0=0.40, ρf0=3.00, ρM=1, ρ_rep=1
t1=2026-08-17, t2=2026-09-20
```

结构对照：Q2 10/11（`βc0=0.11730, u1=0.44216, α=0.22953`，`t2=2026-10-11`）。

### 2.5 初值

对每个省在 `startDate`：

```text
C0, M0 取省级累计（缺失按 0 并标记）
inc = 前 7 日日均新增病例
dinc = 前 7 日日均新增死亡
a = α+γ+μ
active = min(inc/a, max(C0-M0,0))
Q0 = 0.4·active; I0 = active-Q0
E0 = min(inc/σ, N-C0)
R0 = max(C0-M0-active,0)
D0 = min(2·dinc, M0)       % 修正：2 天延迟 × 日死亡
S0 = N-E0-I0-Q0-R0-M0
```

> 旧骨架写 `D0=dinc*(2/7)` 是错的，本文改为 `2*dinc`。

## 3. 标定

### 3.1 标定参数

`beta_mult_i`（8 个）表示省级本地传播差异：

- 高负担省（Ituri、Nord-Kivu、Haut-Uele、Tshopo）允许 [0.5, 2.5]；
- 低负担省（Bas-Uele、Nord-Ubangi、Sud-Kivu、Sud-Ubangi）收缩到 [0.5, 2.0] 并加正则；
- 其他参数固定为 Q2 值，不重新拟合 13 参数。

### 3.2 目标

```text
J = Σ_i [log(C_model,i(10/25)+1) − log(C_obs,i(10/25)+1)]²
    + λ · Σ_i (beta_mult_i − 1)²
```

- 目标日期：2026-10-25；
- 初值：2026-06-21；
- 观测：省级累计确诊；
- `ρ_rep=1` 作为主假设（模型 C 与确诊同口径的近似）；
- 低病例省权重降低，避免 2 例省主导。

### 3.3 验证

- 10/26–11/09 省级净增；
- 与“10/18–10/25 净增 × 15/7”的持平基线比较 MAE；
- 报告每省误差，不只报总数。

## 4. 传播阈值

冻结参数、`s_i=S_i/N_i`：

```text
a=α+γ+μ, b=γQ+μQ

K_ii = s_i beta_mult_i [βc/a + αβh/(ab)
       + (βf/ν)(μ/a + αμQ/(ab))]

K_ij = s_i βc beta_mult_j w_ij P_ij / a   (i≠j)

R_net = ρ(K)
R_local,i = K_ii
```

- `R_local,i<1`：切断省际联系后该省不能自持；
- `R_net<1`：网络衰减；
- `R_net>1`：网络超临界；
- 两节点条件 `K12K21=(1-K11)(1-K22)`。

## 9. 当前实现与结果边界（2026-11-19）

`run_q4_spatial` 已跑通，输出在 `ws/new/outputs/q4/`。当前结果：

- 高负担省（Ituri/Nord-Kivu/Haut-Uele/Tshopo）按 10/18+10/25 累计标定；
- 低负担省固定 `beta_mult=1`，避免 2–13 例省主导 `R_net`；
- 10/25 拟合：Ituri 7421 vs 7211，Nord-Kivu 2310 vs 2309，
  Haut-Uele 448 vs 436，Tshopo 83 vs 83；
- 留出期 MAE：模型 **179.06** vs 持平基线 **18.04**；
- `R_net`：**2.31**（条件于当前 beta_mult/P，模型留出期明显高估）。

这不是“最终预测”，而是当前骨架的边界：

1. 10/25 后模型仍按同一 `betaMult` 增长，但观测在 10/25–11/09 已明显减速；
2. 低负担省 6/21 无记录，按 0 初始化，导致 Bas-Uele/Nord-Ubangi 等被低估；
3. `ρ_rep=1` 是近似，模型 C 与确诊口径不一致；
4. 因此 **R_net=2.31 不能当作真实阈值**，只能作为“当前结构与参数下”的诊断；
5. 下一步应加 10/25 后的控制/报告变化，或只用 10/25 状态做短窗口策略比较。

## 10. 局限

1. `P` 是情景代理，不是实测 OD；
2. `beta_mult` 标定会吸收报告率/年龄结构/行为差异，不能解释为纯传播力；
3. 8 省日数据不平衡，低病例省初值是假设；
4. `ρ_rep=1` 是近似，确诊≠发病；
5. 策略效果（旅行限制/疫苗）是情景参数，不是本题数据估计；
6. `R_net` 是阈值诊断，不是病例预测；
7. 跨境只有累计快照，分支过程的 `m,k,n` 是情景，不是估计。
